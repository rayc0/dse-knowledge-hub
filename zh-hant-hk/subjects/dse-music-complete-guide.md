# DSE音樂科完全攻略——內地生家長及考生必讀

DSE音樂科（Music）是香港高中熱門選修之一，特別適合有正統音樂底子的考生。對於自小學琴、考過中央音樂學院或中國音協級別、又想喺DSE拎高分的內地生嚟講，音樂科絕對係將「興趣」變成「分數」嘅最佳橋樑。本文由考試架構、選科策略到溫書時間分配，全面拆畀你睇。

## 一、考試架構速覽

DSE音樂科分為三大範疇，分數比例如下：

| 考試部分 | 佔分 | 形式 |
|---|---|---|
| 卷一：聆聽試卷（Listening） | 約40% | 筆試，需聽錄音作答 |
| 卷二：演奏（Performing） | 約30% | 校本評核（SBA）現場演奏 |
| 卷三：創作（Creating） | 約30% | 校本評核（SBA）提交作品 |

> **溫馨提示：** 校本評核（SBA）合共佔約六成分數，一旦失手就難以翻身，必須由中五開始認真對待。

## 二、聆聽試卷（卷一）攻略

### 2.1 考試基本資料

- **時間**：約 1 小時 30 分鐘
- **題型**：多項選擇題、簡答題、填表題、樂段分析題
- **應考模式**：試場內播放錄音，考生邊聽邊答

### 2.2 考核範圍一覽

| 範疇 | 涵蓋內容 |
|---|---|
| 樂理基礎 | 音符時值、拍子記號、調號、終止式、音程辨認 |
| 風格辨識 | 巴洛克、古典、浪漫、印象派、爵士、二十世紀、流行曲 |
| 曲式分析 | 二段體、三段體、奏鳴曲式、迴旋曲式、主題與變奏 |
| 作曲家及作品 | 巴赫、莫扎特、貝多芬、華格納等；兼顧中國傳統音樂 |
| 樂器音色 | 西洋管弦樂器、中國樂器音色辨識 |
| 世界音樂 | 非洲鼓樂、印度拉格、日本雅樂等文化背景 |

### 2.3 內地生嘅強項與弱項

| 範疇 | 內地生強項 | 需補課內容 |
|---|---|---|
| 中國傳統音樂 | 熟悉二胡、琵琶、古音色及五聲音階 | 加強粵劇、南音等本地傳統 |
| 西洋樂理 | 級別試底子扎實 | 補課曲式分析（非級別試重點） |
| 西方作品歷史 | 熟聽巴赫、貝多芬 | 加強二十世紀及當代作品 |
| 世界音樂 | 接觸較少 | 需專項操練非洲、印度、日本音樂 |

## 三、演奏部分（SBA）完全拆解

### 3.1 評核要求

- 演奏 **2 至 3 首** 樂曲，總長度約 **5 至 10 分鐘**
- 可獨奏或組合演奏（合奏不可超過總長度一半）
- 由校內音樂科老師評分，再交由考評局作校外審核

### 3.2 揀曲攻略

| 考慮點 | 貼士 |
|---|---|
| 技術難度 | 自己穩陣應付嘅曲目，約 ABRSM Grade 7—8 程度 |
| 風格多樣 | 兼顧不同時期或樂派（如古典 + 中國 / 現代） |
| 詮釋空間 | 揀有明顯情感起伏嘅曲目，顯出個人演繹 |
| 避免撞曲 | 唔好揀太多人考嘅「大路」曲目，與老師商量 |

### 3.3 內地級別試 vs ABRSM 對照

| 內地級別 | 約等於 ABRSM | DSE 適用程度 |
|---|---|---|
| 中央院 / 中國音協 8 級 | Grade 6—7 | 可以，但宜再提升 |
| 中央院 / 中國音協 9—10 級 | Grade 7—8 | 適合 DSE 演奏要求 |
| 音樂學院附中水平 | 超越 Grade 8 | 完全達標，宜進取揀曲 |

> **重要提醒：** DSE 演奏評分睇嘅唔止係「手指快唔快」，更重視樂句呼吸、情感處理同舞台台風。內地級別試偏重技術準繩，宜喺詮釋方面多下功夫。

## 四、創作部分（SBA）完全拆解

### 4.1 評核要求

- 提交 **1 至 2 件** 個人原創作品
- 形式不限：器樂曲、電子音樂 / MIDI、歌曲創作等均可
- 必須附上**創作理念書**，解釋構思、技術運用等
- 作品總長度約 **2 至 5 分鐘**

### 4.2 評分維度

| 評分項目 | 評審重點 |
|---|---|
| 音樂素材運用 | 旋律、和聲、節奏是否有條理地發展 |
| 曲式結構 | 段落佈局是否合理、具邏輯 |
| 創意與個性 | 作品有冇獨特音樂想法 |
| 技術執行 | 樂譜排版、錄音質素是否專業 |
| 創作理念書 | 文字說明能否清晰交代創作動機與手法 |

### 4.3 創作小貼士

- 由自己最熟悉嘅樂器或風格出發，較易發揮水準
- 大膽融合中西元素（如鋼琴曲加入五聲音階主題）可獲加分
- 中五暑假開始構思，與校內音樂科老師保持每月匯報

## 五、咩人適合揀音樂科？

### 5.1 適合嘅考生類型

| 條件 | 說明 |
|---|---|
| 樂器程度 | ABRSM Grade 5 或以上，能穩定演奏考試曲目 |
| 樂理底子 | 識譜、明白和聲與基本曲式 |
| 創作興趣 | 對作曲有熱誠或已有初步作品 |
| 時間投入 | 願意持續練樂器，不會因公開試減練習量 |
| 升學目標 | 打算報讀音樂相關學位，或以音樂作加分王牌 |

### 5.2 唔建議揀嘅情況

| 情況 | 原因 |
|---|---|
| 樂器程度低過 Grade 5 | 演奏 SBA 難以達標 |
| 完全冇樂理根底 | 聆聽卷難度偏高，短期難補底 |
| 想「臨急抱佛腳」拎高分 | 音樂科唔係背誦科，難靠衝刺 |
| 其他選修已佔據大量時間 | 演奏同創作 SBA 需長期投入 |

## 六、每週工作量估算

| 項目 | 每週時數 |
|---|---|
| 樂器練習（維持 + 提升） | 3 — 5 小時 |
| 樂理 / 聆聽操練 | 2 — 3 小時 |
| 創作作品構思及修改 | 1 — 2 小時 |
| **合計** | **約 6 — 10 小時 / 週** |

> 音樂科係 DSE 選修之中工作量較重嘅一科，但對熱愛音樂嘅學生嚟講，大部分時間本來就用喺練琴上，額外備試負擔相對合理。

| 院校 | 課程名稱 | 課程特色 |
|---|---|---|

| 香港浸會大學（HKBU） | 音樂系（BA in Music） | 多元化，涵蓋流行音樂製作及演奏 |

| 香港演藝學院（HKAPA） | 音樂學院（表演 / 作曲） | 專業表演導向，唔屬八大資助 |

### 7.1 DSE 入學要求參考

| 課程 | 一般收生成績 | 額外要求 |
|---|---|---|
| HKU 音樂系 | 最佳 5 科約 25 分或以上 | 需面試（演奏 + 聆聽測試） |
| HKBU 音樂系 | 最佳 5 科約 22 分或以上 | 需面試 |
| HKAPA 音樂學院 | DSE 僅供參考 | 以專業試音（Audition）為主要收生準則 |

## 八、內地生備試額外攻略

1. **認識本地音樂文化**：補習粵劇、語流行曲發展史，聆聽卷有機會出現
2. **曲式分析專項操練**：中央院級別試冇呢部分，需要另外補課
3. **世界音樂專題**：非洲鼓樂、印度拉格、日本雅樂係內地學生最弱嘅聆聽範疇，宜早啲開始聽
4. **樂譜軟件必須識**：創作提交需用 Sibelius、MuseScore 等排版，建議中四暑假開始學
5. **建立音樂英語詞彙表**：DSE 聆聽卷以英文出題，必背 tempo、dynamics、texture 等術語

## 九、全年備考時間表建議

| 階段 | 建議工作 |
|---|---|
| 中四暑假 | 熟習 DSE 樂理課程、購買聆聽練習套裝、學習樂譜軟件 |
| 中五上學期 | 每日練琴 1 小時、開始曲式分析練習、構思 SBA 演奏曲目 |
| 中五聖誕假 | 完成第一首 SBA 演奏錄音、開始創作初稿 |
| 中五下學期 | 鎖定 2—3 首演奏曲目、聆聽卷歷屆試題操練、提交創作理念書初稿 |
| 中五暑假 | 完成 SBA 演奏及創作定稿、補課世界音樂及粵劇章節 |
| 中六開學 | 聆聽卷密集操練、模擬試操練、調整演奏演出細節 |
| 考試前兩個月 | 重溫聆聽卷錯題、演出綵排、心理調整 |

## 十、總結

DSE 音樂科係一門高度講求「長期累積」嘅選修，難以靠短期衝刺拎星。對樂器已達 ABRSM Grade 5 以上、樂理根底穩固嘅內地生而言，音樂科係將個人專長轉化為公開試分數嘅絕佳跳板。**三大攻略重點係：強化聆聽卷嘅曲式分析與世界音樂知識、用心揀曲並提早錄製 SBA 演奏、預留充足時間創作原創作品。** 做好呢三樣，音樂科隨時成為你 DSE 嘅星級選修。
