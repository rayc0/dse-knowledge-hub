# DSE 設計與應用科技（DAT）全面攻略：內地學生備考懶人包

## 科目速覽

設計與應用科技（Design and Applied Technology，簡稱 DAT）係 DSE 嘅選修科之一，將設計思維、工程原理同實作技能集於一身。同其他「揸筆就考」嘅科目唔同，DAT 非常重視落手做同成個設計過程，要求學生由概念一路做到成品，完成一個完整嘅設計循環。

如果你係內地嚟港嘅學生，本身有美術底、雙手靈活，或者打算報讀設計、工程、建築相關嘅大學課程，DAT 絕對係一個極具吸引力嘅選修。

## 評估架構

DAT 嘅評估分為三大板塊：

| 評估部分 | 內容 | 佔分比重 | 備註 |
|---------|------|---------|------|
| 卷一（筆試） | 設計知識與理解（選擇題＋結構題） | 35% | 涵蓋材料學、產品分析、人體工學等 |
| 設計習作（SBA 項目一） | 設計過程檔案（設計思維紀錄） | 30% | 全學年持續進行，校內評核 |
| 實作項目（SBA 項目二） | 實物製作＋專題報告 | 35% | 喺學校工場造一件完整嘅設計成品 |

**最大特點**：DAT 係 DSE 之中 SBA（校本評核）比重數一數二高嘅科目，超過六成份數嚟自校內持續評核，而唔係一次過嘅公開考試。

## 卷一：書面試卷拆解

### 涵蓋嘅知識範疇

| 主題 | 具體內容 |
|------|---------|
| 設計過程 | 設計循環（Design Cycle）、用家研究、需求分析 |
| 材料與製造 | 木材、金屬、塑膠、複合材料嘅特性與加工工藝 |
| 產品分析 | 功能性、美觀性、人體工學、可持續性分析 |
| 繪圖技能 | 等角投影（Isometric Drawing）、正投影（Orthographic Drawing） |
| 電子與控制 | 基本電路、感測器、控制系統（部分課程涵蓋） |
| 人體工學 | 人體尺寸標準、用家友善設計原則 |
| 可持續設計 | 生命週期分析、環保材料選用、循環經濟設計 |

### 題型分佈

| 題型 | 說明 |
|------|------|
| 多項選擇題 | 測試基礎設計知識同材料特性 |
| 結構題 | 分析產品設計圖、指出設計問題、提出改善建議 |
| 延伸題 | 設訂特定情境，綜合評價一個設計方案 |

## 設計習作（SBA 項目一）：成個設計過程嘅紀錄

設計習作係對學生**設計思維過程**嘅系統性紀錄，通常以 A3 畫板或者數碼檔案形式呈現。

### 評核重點一覽

| 階段 | 內容 | 評分要點 |
|------|------|---------|
| 1. 情境分析 | 釐清設計問題，分析用家需求 | 研究深度、定義問題嘅清晰度 |
| 2. 設計資料搜集 | 參考現有產品、研究材料 | 資料嘅闊度與相關性 |
| 3. 設計構思 | 多個設計方案嘅草圖 | 創意多樣性、可行性 |
| 4. 方案篩選 | 評價並選定最合適方案 | 判斷力、選擇嘅理據 |
| 5. 詳細設計 | 繪製詳細工程圖 | 繪圖準確度、標註齊全 |
| 6. 原型製作 | 模型或實物初稿 | 工藝質素 |
| 7. 測試評估 | 測試成品功能，對照設計要求 | 測試方法、批判性評價 |
| 8. 反思改良 | 記錄改善建議同學習反思 | 自我評估能力 |

**重要提醒**：老師睇嘅係**設計思維嘅完整性**，而唔係最終件作品有幾靚。一份問題識別清晰、資料搜集充足、迭代合理嘅習作，比起華麗但過程空泛嘅習作，分數一定高過後者。

## 實作項目（SBA 項目二）：親手整件成品出嚟

實作項目要求學生喺學校工場內，獨立完成一件完整嘅設計製品。

### 評分準則

| 評分維度 | 比重 | 說明 |
|---------|------|------|
| 工藝質素 | 高 | 切割、接合、表面處理嘅精細度 |
| 功能實現 | 高 | 成品能否正常運作 |
| 設計一致性 | 中 | 實物是否同設計習作中嘅方案吻合 |
| 專題報告 | 中 | 製作過程記錄、遇上嘅難題與解決方法 |
| 創意展現 | 中 | 設計有冇獨特之處 |

### 常見實作項目類型

- 家具小品（例如摺疊式書架、燈具設計）
- 生活用品（例如環保餐具架、收納裝置）
- 玩具或教育產品（例如益智拼圖、模型）
- 簡單電子裝置（例如感應燈、智能收納盒）

## 三維設計與數碼工具

而家嘅 DAT 課程愈來愈重視數碼設計工具嘅運用：

| 工具類別 | 常用軟件 |
|---------|---------|
| 2D 繪圖 | AutoCAD（基礎）、Adobe Illustrator |
| 3D 建模 | SketchUp、Fusion 360、Tinkercad |
| 渲染與展示 | Keyshot、Blender（進階） |
| 排版設計 | Adobe InDesign（設計習作用） |

內地學生如果本身有相關軟件底子，整設計習作嘅時候會有明顯優勢。

## 對接大學專業

DAT 成績獲以下類型嘅大學課程認可：

| 大學專業 | 與 DAT 嘅關聯度 | 主要院校 |
|---------|---------------|---------|
| 工業設計 | 極高 | 香港理工大學（PolyU） |
| 產品設計 | 極高 | 香港理工大學、香港知專設計學院 |
| 建築學 | 高 | 港大、中大、理大建築系 |
| 室內設計 | 高 | 香港理工大學、香港設計學院 |
| 視覺傳達設計 | 中高 | 香港理工大學 |
| 機械工程 | 中 | 各間大學工程學院 |
| 科技教育 | 高 | 香港教育大學 |

**溫馨提示**：報讀設計類大學課程，一般仲要額外呈交**作品集（Portfolio）**。DAT 嘅設計習作同實作項目，正好係建立作品集嘅核心素材。

## DSE DAT 同內地相關課程嘅比較

內地高中並冇完全對應嘅「設計與應用科技」科目，但通用技術課、資訊科技課、勞動課等都有部分相似元素：

| 比較維度 | DSE DAT | 內地相關課程 |
|---------|---------|------------|
| 課程定位 | 正式選修科，計入 DSE 成績 | 多數為必修課，唔計入高考 |
| 實作深度 | 深，有完整項目製作要求 | 較淺，以示範或簡單操作為主 |
| 設計思維訓練 | 系統化（設計循環） | 較少系統化訓練 |
| 數碼工具應用 | 鼓勵使用 3D 軟件 | 資訊科技課有基礎操作 |
| 大學銜接 | 直接對接設計/工程專業 | 主要服務高考文理科選擇 |

## 內地學生嘅備考優勢與挑戰

### 具備嘅優勢

- **藝術培訓底子**：內地好多學生都接受過專業美術訓練（素描、色彩、立體構成），呢啲技能可以直接轉化為 DAT 嘅優勢
- **數理基礎紮實**：內地嘅理科訓練有助理解材料力學、電路等工程原理
- **勤勞同執行力強**：內地學生面對耗時嘅項目製作，通常都幾捱得
- **3D 軟件經驗**：部分內地學生已經自學咗 SketchUp、Fusion 360 等軟件

### 需要克服嘅挑戰

- **設計思維要轉換**：內地培訓偏重技法（畫得似），DSE 更重視「解決問題」嘅設計思維
- **工場安全規程要熟習**：香港學校工廠有嚴格嘅安全守則，內地學生需要時間適應
- **英文書面表達**：卷一同項目報告都要用英文作答
- **時間管理**：設計習作同實作項目佔用大量課餘時間，要做長線規劃

## 拎高分策略

### 設計習作高分貼士

1. **過程重於成品**：每個設計決定都要用文字解釋理由（例如「我揀 A 方案係因為……」）
2. **用家研究要做實**：進行真實嘅用家訪談或問卷，將結果反映喺設計入面
3. **排版要整潔專業**：習作嘅視覺效果影響第一印象，但內容先至係評分核心
4. **製作過程要影相**：每個製作步驟都影低，整理入專題報告
5. **測試要夠客觀**：測試時記錄數據（例如強度測試、用家使用測試），唔好淨係寫「測試成功」

### 卷一備考貼士

1. **熟記材料特性對照表**：呢類係選擇題嘅高頻考點（例如「邊種材料最適合……」）
2. **勤練工程圖**：等角投影同正投影圖係必考內容，需要大量練習
3. **人體工學數據要記住**：常用人體尺寸標準（例如桌椅高度、扶手闊度）
4. **產品分析框架**：SCAMPER（替換、結合、調整、改造、另作他用、刪減、重排）係常用工具

## 結語

DAT 係 DSE 之中少數可以「以作品說話」嘅科目，對有設計天份同動手能力嘅學生而言，係一門性價比極高嘅選修。內地學生若有美術培訓背景或理工興趣，可以盡情發揮所長；關鍵在於由「展示技法」嘅思維模式，轉為「記錄設計思維」，並且積極培養英文書面表達能力。
