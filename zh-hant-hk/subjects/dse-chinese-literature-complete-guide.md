# DSE中國文學完全攻略：內地學生備試指南

## 科目簡介

中國文學（Chinese Literature）是DSE的選修科目之一，專注中國古典及現代文學作品的閱讀、鑑賞與分析。與「中國語文」側重語言運用不同，中國文學更接近文學批評——要求學生深入理解文本意境、藝術手法，並以書面形式表達文學見解。

對文學有興趣、文言文底子扎實的內地學生而言，中國文學是一科競爭對手相對較少、但高分潛力突出的選修科。

## 試卷結構

DSE中國文學共設兩份試卷，全卷以中文（正體字／繁體字）作答：

| 卷別 | 內容 | 題型 | 佔分比重 | 考試時間 |
|------|------|------|---------|---------|
| 卷一 | 文學鑑賞與評論（指定作品） | 必答題＋選答題（短答＋論述） | 55% | 2小時30分 |
| 卷二 | 文學選讀（獨立篇章分析） | 賞析題＋創意寫作／比較分析 | 45% | 2小時30分 |

### 卷一：指定作品

課程涵蓋約15–20篇指定作品，橫跨三大文類：

- **詩歌**（古典詩詞為主，兼及現代詩）
- **散文**（古典散文＋現代抒情散文）
- **小說**（古典短篇＋現代長篇章節）

考生須對指定作品有深厚認識，能引述原文並作出文學分析。

### 卷二：獨立篇章

提供考生未曾預習的文學選段，測試其文學感知力與即場分析能力。考生須：

- 析解篇章主題意蘊
- 分析寫作技巧（意象、語言風格、敘事手法等）
- 回應比較分析或創意延伸寫作題

## 課程涵蓋的文學範圍

### 古典文學（佔課程約60–65%）

| 類別 | 代表作品／作家 |
|------|---------------|
| 先秦散文 | 《論語》、《孟子》、《莊子》寓言 |
| 漢代賦文 | 《赤壁賦》（蘇軾）等 |
| 唐詩 | 李白、杜甫、王維、白居易等 |
| 宋詞 | 蘇軾、辛棄疾、李清照等 |
| 明清小說節錄 | 《紅樓夢》、《聊齋誌異》等 |
| 元曲 | 關漢卿、馬致遠等 |

### 現代文學（佔課程約35–40%）

| 類別 | 代表作家 |
|------|---------|
| 現代散文 | 朱自清、余光中（台灣）、張愛玲（香港／上海） |
| 現代小說 | 魯迅、沈從文、白先勇 |
| 現代詩 | 余光中、席慕蓉、鄭愁予等 |
| 香港文學 | 西西、也斯等本土作家 |

## DSE中國文學與內地語文學文教育的比較

| 面向 | DSE中國文學 | 內地高中語文（文學部分） |
|------|-----------|----------------------|
| 課程定位 | 獨立文學科目，深度鑑賞 | 語文課程的組成部分 |
| 作品選取 | 香港本土文學比例較高 | 內地當代文學為主 |
| 考核方式 | 論述式文學評論，不設標準答案 | 有客觀題，論述題有參考答案 |
| 文言文比重 | 高（約60%以上） | 約20–30% |
| 創意寫作 | 有（仿寫、延伸寫作） | 有，但比重較低 |
| 台灣／香港文學 | 納入正式課程 | 極少涉及 |
| 詮釋空間 | 大，鼓勵個人見解 | 較小，有「標準」詮釋 |

**最關鍵差異**：DSE中國文學鼓勵考生提出個人文學見解，只要言之有據，不同詮釋同樣可得分。這跟內地「找標準答案」的閱讀理解思維截然不同。

## 內地學生的優勢與弱項

### 優勢

- **古典文學底蘊**：內地語文教育自小強調背誦，對唐詩宋詞、文言散文的積累遠超本地學生
- **文言文閱讀能力**：理解文言文是DSE中國文學的核心競爭力之一
- **文學理論基礎**：內地初中高中的文學鑑賞訓練（意象、煉字、主題分析）與DSE要求高度對接
- **寫作邏輯**：內地學生寫議論文的邏輯性普遍較紮實

### 弱項

- **香港／台灣文學陌生**：西西、也斯、余光中等作家在內地課程中幾乎不涉及
- **繁體字書寫**：全卷須以繁體字作答
- **「主觀詮釋」思維**：內地學生習慣找「正確答案」，需學會表達並捍衛個人文學見解
- **現代詩鑑賞**：現代詩（尤其台灣現代詩）的意象體系與內地現代詩風格有所不同

## Level 5+ 備試策略

### 一、建立「文學鑑賞框架」

高分答案並非堆砌術語，而是有結構地分析文本：

**詩歌鑑賞框架**：
1. 意象（Image）→ 作者選取哪些意象？
2. 情感（Emotion）→ 意象傳達何種情感？
3. 技巧（Technique）→ 用上甚麼修辭、聲韻、對仗？
4. 效果（Effect）→ 這些技巧怎樣強化表達效果？

**散文鑑賞框架**：
1. 敘事／抒情方式 → 第一人稱敘事？借物抒情？
2. 語言風格 → 樸素自然抑或華麗鋪陳？
3. 結構布局 → 起承轉合的設計
4. 主題昇華 → 作者最終想表達的人生哲理

### 二、指定作品的備試方法

- **精讀而非泛讀**：每篇指定作品須達到「能引原文、能析手法、能評主題」的深度
- **製作「作品檔案卡」**：每篇作品一張卡，記錄主題、關鍵意象、寫作手法、名句
- **理解創作背景**：了解作者所處時代與創作意圖，有助深化分析
- **橫向比較**：考試或要求比較兩篇作品，平時宜練習跨篇分析

### 三、卷二即場分析訓練

- 每星期練習1–2篇「未見過」的文學作品分析，限時30分鐘
- 培養「快速抓主題」的能力：閱讀一篇文稿，2分鐘內鎖定主題與核心意象
- 創意延伸寫作：須與原文主題保持一致，風格互相呼應

### 四、論述題寫作規範

| 要素 | 說明 |
|------|------|
| 論點鮮明 | 首段須清晰表明分析角度或個人見解 |
| 引文準確 | 引用原文須準確（繁體字），並加上引號 |
| 分析深入 | 解釋引文如何支持論點，不能只羅列手法名稱 |
| 結構完整 | 每個論點獨立成段，段落之間有清晰過渡 |
| 結論有力 | 總結全文，昇華至更宏觀的文學或人文意義 |

## 中國文學對大學升學的幫助

| 大學學科 | 中國文學的關聯度 |
|---------|---------------|
| 中國語言文學（所有院校） | 極高，直接對口專業 |
| 比較文學 | 高，跨文化文學分析能力高度契合 |
| 翻譯學 | 高，深厚的中文文學根柢是基礎 |
| 文化研究 | 高，香港／台灣文學涉及文化身分議題 |
| 新聞傳播 | 中等，寫作能力有助提升 |
| 歷史學 | 中等，文言文閱讀能力有助解讀史料 |

## 選科建議

中國文學適合以下類型的學生：

- 對中國古典文學有濃厚興趣，課外有大量閱讀習慣
- 中文寫作能力強，擅長表達個人見解
- 目標為人文社科類大學學科
- 不介意大量閱讀和背誦指定作品
- 希望選修一科與中文語文差異化、但知識互補的科目

**不建議選修的情形**：以數理為主的學生，若非真正熱愛文學，選修中國文學或許不如BAFS或ICT更具實際效用。

## 總結

DSE中國文學是一科「門檻不低，但上限極高」的科目。對古典文學底子扎實的內地學生而言，這是一個彎道超車的機會——只要克服繁體書寫和「主觀詮釋」思維的轉變，配合系統的備試策略，Level 5乃至5**均值得期待。
