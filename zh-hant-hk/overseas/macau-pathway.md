# DSE考生澳門升學懶人包2026：澳大、科大、理工英文授課與逗留簽證全攻略

對好幾代香港DSE考生嚟講，澳門一直被當成「次選」甚至「冇諗過」嘅升學出路。其實呢條路一啲都唔差：搭船一個鐘、踩港珠澳大橋半個鐘到，講廣東話冇隔閡，學費比英澳平一大截，部分學校QS排名仲高過香港八大以外嘅好多院校。更加關鍵嘅係——喺澳門讀書期間，你嘅香港永久居民身份同居港時間都可以保留落嚟。呢篇文章用2026/27學年最新政策做基礎，逐一拆解DSE點樣申請澳門六間主要高校、英文門檻點計、學費獎學金幾錢、學生逗留許可點樣搞，再比較畢業後回港做嘢同留澳發展兩條路，幫你判斷澳門值唔值得放入Non-JUPAS組合。

## 一、點解DSE學生應該認真考慮澳門

**第一，收生門檻比較鬆手。** 澳大對2024年起嘅DSE考生只要求4C2級核心加兩科選修3級，相比JUPAS八大動輒要「3322+33」而且實際收生分數遠高過呢條線，澳大門檻低足足一級；澳科大、澳門理工更低。

**第二，英文授課已經係主流。** 澳大幾乎全部本科都係英文授課，澳科大八成以上都係英文教學，對DSE英文科唔算差、又唔想放棄英語學術訓練嘅同學非常友好。

**第三，學費成本可控。** 澳大非本地生每年學費大約12.26萬澳門元（約13.4萬港幣），澳科大主流學院大約17萬澳門元；對比英國倫敦嘅25萬至35萬港幣、美國私立大學40萬港幣起跳，四年讀落可以慇返接近一百萬港紙。

**第四，香港永久居民身份唔會自動失效。** 香港DSE學生去澳門讀書屬於「出境讀書」，根據《入境條例》，只要喺38個月觀察期內返夠日子，原則上唔會自動喪失永久居民身份；香港身份證亦可以繼續使用。畢業後返港揾工唔使搞IANG，直接用HKID見工就得，唔似外地畢業生要帶住「非本地畢業生」標籤。

**第五，澳門高校獨立招生**，唔入JUPAS系統，唔會佔用JUPAS 20個志願，等於多咗一重保險。

## 三、澳門大學（UM）DSE入學要求逐項拆解

UM係澳門唯一打入QS世界前300嘅綜合型公立大學。佢對香港DSE嘅收生規矩（2024年文憑起適用）如下：

- **英國語文：3級或以上**
- **中國語文：3級或以上**
- **數學（必修部分）：2級或以上**
- **公民與社會發展科：達標（Attained）**
- **兩科選修科目（甲類）：3級或以上**

**學院附加要求：**

- 申請**科技學院**（計算機、土木、機械、電機、數學）：物理須3級或以上
- 申請**健康科學學院**（生物醫學、藥學等）：化學須3級或以上
- 申請**人文學院、社會科學學院、工商管理學院、法學院、教育學院**：冇指定選修科要求，但建議英文4級以上以提升競爭力

**額外英語能力證明**（非強制，但有助獎學金審批）：IELTS 6.0、TOEFL iBT 80、SAT閱讀加寫作600、ACT 22。

**申請時間表（2026/27學年）：**

- 網上報名：2026年2月3日至4月9日
- 繳交報名費：MOP 250
- 上傳成績單及證明文件截止：4月16日
- 面試安排（部分專業）：5月至6月
- 最後錄取通知：7月中下旬，與DSE放榜（7月16日）幾乎同步

**學費同住宿（2026/27估算）：**

- 學費：MOP 122,600/年（約HK$134,500），四年合共約54萬港幣
- 住宿式書院（Residential College）費用：MOP 16,500/年（約HK$18,100）
- 雜費、醫療保險：約MOP 5,000/年

UM最大特色係**住宿式書院制**，所有本科生要住校四年，同香港中文大學嘅書院制相似，可以畀到高密度嘅師生交流同跨學科社交。

## 四、澳門科技大學（MUST）申請重點

澳科大2026/27學年對香港DSE嘅最低門檻為**4科核心加1科選修各達2級以上**，比起UM更低，但熱門專業嘅實際收生分數會被推高：

- **醫學院（MBBS）**：要求總分至少18分（最佳5科），生物、化學各3級以上，要面試同英語筆試
- **中醫藥學院**：核心科目4C2，化學、生物各3級以上
- **酒店與旅遊管理學院**：英文3級或IELTS 5.5
- **資訊科技學院**：數學2級，物理或M1/M2優先
- **人文藝術學院**：作品集（設計專業）

**學費（2026/27非本地生，參考最新公布）：**

| 學院 | 年學費（澳門元） | 四年總學費（約） |
|------|----------------|----------------|
| 醫學院 MBBS | 179,000 | 716,000 |
| 工商管理學院 | 174,000 | 696,000 |
| 酒店與旅遊管理學院 | 174,000 | 696,000 |
| 資訊科技/工程 | 170,000 | 680,000 |
| 藝術與設計學院（5年制） | 258,000 | 約130萬 |

申請窗口：**2025年11月至2026年6月**滾動審理，**先到先得，滿額即關**。強烈建議2026年1月前遞表，避免熱門專業（醫學、中醫藥、酒店管理）截止。

獎學金方面，澳科大對DSE 5科5\*以上嘅學生提供「傑出新生獎學金」，最高金額為四年全額學費加每月MOP 5,000生活津貼。

## 五、澳門理工大學（MPU）同其他選擇

**澳門理工大學**係公立應用型大學，2022年由原澳門理工學院升格，主打翻譯、藝術、護理、博彩管理。DSE要求4C加1科選修2級以上，部分專業（如視覺藝術）要作品集或者面試。學費大約**MOP 48,000/年**（約HK$53,000），係六校之中最平之一，四年總學費只係約21萬港紙。報名費MOP 300。

**澳門城市大學（CityU Macau）**係私立綜合型大學，DSE門檻最低（4C即可），適合作為保底，學費約MOP 92,000/年。

**聖若瑟大學（USJ）**係全英文授課嘅天主教大學，規模細但師生比高，心理學、建築、宗教研究有特色，學費MOP 58,000至95,000/年不等。

**澳門旅遊大學（UTM）**前身係IFT，旅遊與酒店專業全球QS前10，但本科課程選擇唔多，學費約MOP 45,000/年。

## 六、英文成績同文件準備清單

DSE校內英文科已經被澳門各校普遍承認，但**強烈建議額外交埋IELTS或TOEFL以提升錄取同獎學金機會**：

- IELTS 6.0（UM/MUST商科、人文）
- IELTS 6.5（UM法學、醫學、傳媒）
- TOEFL iBT 80（多數專業接受）

**申請文件清單：**

1. DSE成績單（放榜後透過香港考評局HKEAA官方寄送，澳門部分院校接受電子版本）
2. HKID同回鄉證副本
3. 高中5至6學年校內成績與品德報告
4. 個人陳述（Personal Statement）500至800字（部分專業要求中英雙版本）
5. 推薦信1至2封（科任老師或班主任）
6. 課外活動/比賽獲獎證明
7. 英語標準化考試成績（如有）
8. 報名費收據

## 七、逗留許可與抵澳手續

香港居民赴澳門讀書，要辦理「**澳門特別行政區學生逗留許可**」（Autorização de Permanência para Estudantes）。流程如下：

1. **錄取通知書**到手之後，由學校代為向澳門治安警察局出入境事務廳遞交申請
2. **處理時間**：約6至8個星期，建議預留兩個月
3. **首次簽發期**：1年，以後每年隨註冊憑證續期
4. **所需文件**：錄取通知書正本、HKID、回鄉證、健康證明、住址證明、近照
5. **費用**：首次簽發MOP 200，每次續期MOP 100

**港澳通行證 vs 學生逗留許可嘅分別：** 港澳通行證只啱短期訪澳；拎住學生逗留許可之後，可以喺澳門長期居住、開銀行戶口、申請醫保、登記手機卡，等於「準居民」待遇。每星期返香港探親唔使額外簽證，憑HKID就可以入境香港。

## 九、畢業之後：留澳定回港？

**回港做嘢（推薦路線）：** 香港DSE考生本身已經係香港永久居民，**畢業後唔使任何簽證**就可以直接返港求職。呢一點比起內地或海外畢業生強好多——佢哋要走IANG（畢業生留港計劃）拎24個月簽證，而你直接用HKID見工就得。

**留澳工作：** 澳門對非本地畢業生留澳設有「**人才引進計劃**」，但門檻高：

- GPA 3.6/4.0以上
- 各科成績90分以上
- 由澳門僱主提供僱傭合約
- 經澳門人才發展委員會審批

唔符合以上條件嘅，就要按《聘用外地勞工法》（俗稱「藍卡」）申請工作許可，由僱主代為申請，年度配額有限，競爭激烈。

**升學到大灣區/海外：** 澳門本科學歷獲中國教育部學位中心認證，可以直接報考香港、內地、英美研究生。澳大、澳科大每年保送一批本科生去英美頂尖院校讀碩士，係港澳兩地學生通往海外嘅隱形跳板。

## 十、申請時間軸同避坑貼士

**2025年11月至2026年1月：** 準備文件、考IELTS、寫PS、敲定院校組合（建議UM衝、MUST穩、MPU/CityU保）。

**2026年2月至4月：** 提交UM、MUST、MPU網上申請；繳報名費；上傳校內成績單。

**2026年5月至6月：** 部分專業面試（醫學、法學、藝術）；準備DSE應試。

**2026年7月16日：** DSE放榜後24小時內補交成績單。

**2026年7月底至8月：** 收錄取通知；繳留位費；辦學生逗留許可。

**2026年9月：** 抵澳門、註冊、開學。

**避坑貼士：**

1. **唔好淨係申請一間。** 澳門六校獨立招生，多申請唔會撞，每多一間只係多MOP 200至500報名費。
2. **小心專業滿額關檔。** MUST、CityU用滾動錄取，2月前遞表命中率最高。
3. **公民與社會發展科必須「達標」**，2024屆起冇「達標」嘅學生UM一律唔收。
4. **港籍生身份要確認。** 部分港生持BNO加特區護照而無HKID永久居民字樣，記得事先確認入學申請勾選嘅「考生類別」為「香港」而非「國際」，否則學費可能會當國際生收（接近一倍）。
5. **唔好當澳門係「保底」敷衍寫PS。** 澳門各校審PS好認真，模板化PS拒收率高。
6. **保留香港居住日數。** 喺澳門讀書期間建議至少每月返港一次，保留香港稅務、公屋、選民登記等紀錄，避免日後申請永居出現爭議。

## 結語

澳門唔係英美澳嘅代替品，而係一條獨立、成熟、性價比極高嘅升學出路。對DSE分數喺18至25分之間嘅港生，澳大加澳科大嘅組合可能比JUPAS八大保底更穩陣；對想體驗全英學術環境又唔願離家太遠嘅同學，澳門提供咗一個無可代替嘅折衷方案。將澳門放落Non-JUPAS組合入面，本質上係畀自己多一個喺大灣區核心圈發展嘅可能性——而呢一點，正正係2026年香港學生最稀缺嘅資源之一。
