# 香港八大 GPA 點計？榮譽學位等級一文睇晒 2026

> 港八大的本科學位沿襲英式榮譽學士（Honours Degree）制度，畢業證書會直接印明 First Class、Upper Second (2:1)、Lower Second (2:2) 或 Third Class。GPA 計法方面，HKU、HKUST、CityU 採 4.3 滿分（A+ = 4.3），其餘五校（CUHK、PolyU、HKBU、LingnanU、EdUHK）採 4.0 滿分（A+ 與 A 同為 4.0）。榮譽等級會直接寫在成績單同學位證上，影響你申請英美港新碩士、IANG 留港搵工，以至返內地報考選調生。

## 一、GPA 同榮譽等級對 DSE 考生同內地生嘅重要性

香港八大的本科學位唔同內地「學士學位 + 畢業證書」兩證制——喺港校，**榮譽等級本身就係學位嘅一部分**，會白紙黑字印喺證書上面（例如 "Bachelor of Business Administration with First Class Honours"）。對 DSE 考生同內地生嚟講，等級嘅影響喺以下幾方面特別明顯：

1. **申請海外碩士（尤其英美頂校）**：牛津、劍橋、Imperial College London、LSE、NUS、港大自家碩士等項目，最低門檻好多都係 **Upper Second (2:1) 或以上**，大約等於 4.0 制 GPA ≥ 3.3，或 4.3 制 GPA ≥ 3.3（少數頂級項目要求 3.5+）。
2. **留服認證**：教育部留學服務中心只認證學位級別（學士／碩士），但榮譽等級會出現喺認證附頁。部分國企、選調生崗位審查時會參考。
3. **IANG 簽證同留港搵工**：四大、投行、政府 AO 普遍要求 **2:1 或以上**，First 往往係入場券。
4. **返內地考公／選調**：以香港學歷報考時，HR 同人事局慣常用「GPA × 換算 = 百分制」嘅方式嚟核，4.0 制低過 3.0 喺競爭激烈嘅崗位基本上無得揀。

## 三、GPA 基礎公式同 HKU 4.3 制示例

### 基礎公式（八校通用）

```
GPA = Σ（課程學分 × 課程績點）÷ Σ 課程學分
```

### HKU 4.3 制成績 — 績點對照

| 等級 | 分數（參考） | 績點（GP） |
|------|--------------|-----------|
| A+ | 90–100 | 4.3 |
| A | 85–89 | 4.0 |
| A− | 80–84 | 3.7 |
| B+ | 75–79 | 3.3 |
| B | 70–74 | 3.0 |
| B− | 65–69 | 2.7 |
| C+ | 60–64 | 2.3 |
| C | 55–59 | 2.0 |
| C− | 50–54 | 1.7 |
| D+ | 45–49 | 1.3 |
| D | 40–44 | 1.0 |
| F | 0–39 | 0 |

### 計算示例（HKU BBA 學生一學期 5 科）

| 課程 | 學分 | 成績 | 績點 | 學分 × 績點 |
|------|------|------|------|-------------|
| ACCT1101 | 6 | A | 4.0 | 24.0 |
| ECON1210 | 6 | A− | 3.7 | 22.2 |
| BUSI1002 | 6 | B+ | 3.3 | 19.8 |
| CAES1000 | 6 | B | 3.0 | 18.0 |
| CCCH9051 | 6 | A+ | 4.3 | 25.8 |
| **合計** | **30** | | | **109.8** |

**SGPA = 109.8 ÷ 30 = 3.66**（大約 Upper Second）

## 四、四級榮譽學位嘅 GPA 分檔（八校主流標準）

各校細節略有不同，但大框架一致。以下係**主流參考區間**（以 4.0 制為例，HKU／HKUST／CityU 用 4.3 制時相應上移）：

| 榮譽等級 | 英文全稱 | 4.0 制 GGPA | 4.3 制 GGPA | 典型獲得比例 |
|----------|----------|-------------|-------------|--------------|
| 一級榮譽 | First Class Honours | **≥ 3.60** | **≥ 3.60** | 約 10%–20% |
| 二級甲等榮譽 | Second Class Honours, Upper Division (2:1) | 3.00–3.59 | 3.00–3.59 | 約 35%–45% |
| 二級乙等榮譽 | Second Class Honours, Lower Division (2:2) | 2.40–2.99 | 2.40–2.99 | 約 20%–30% |
| 三級榮譽 | Third Class Honours | 1.70–2.39 | 1.70–2.39 | 約 5%–10% |
| 及格學位 | Pass Degree（無榮譽） | 1.00–1.69 | 1.00–1.69 | < 5% |

**留意**：
- HKUST 採用「雙軌」判定：**Major CGA** 同 **Overall CGA 都必須達到對應區間**，以較低一檔為準。
- HKU 除 GGPA 外仲有「**50% 規則**」：至少一半學分必須係 letter-graded（字母評分）課程，否則只會獲頒 Pass Degree，冇榮譽。
- 各院校官方網站嘅閾值會每年微調，**以當年官方公佈為準**。

## 五、HKU / CUHK / HKUST 三校畢業 GPA 嘅細節差異

### HKU — GGPA（Graduation GPA）

- GGPA 覆蓋**所有已修課程**，**包含 F**（唔及格課程仍會計入分母，並以 0 績點計算）。
- 設有 SGPA（學期）、YGPA（年度）、CGPA（累計）、**GGPA（畢業）** 四種 GPA，只有 GGPA 用於榮譽判定。
- 「50% 規則」：如以 P/F（通過／不通過）記分嘅課程超過總學分一半，**不授予榮譽**，只頒 Pass Degree。

### CUHK — Cumulative GPA

- A+ 與 A 同為 4.0（**冇 4.3 制**）。
- 榮譽由 Cumulative GPA 決定；部分書院、雙學位項目設最低畢業 GPA 2.0 要求。
- **酌情權（Discretionary rule）**：成績處於分檔邊界時，院系可依據專業課程表現上下調動一檔。

### HKUST — MCGA + Overall CGA 雙軌

- **Major CGA（MCGA）**：只計算專業必修 + 專業選修。
- **Overall CGA**：計算所有學分課程。
- 榮譽由**兩者中較低一檔**決定：例如 Overall 3.7 但 MCGA 3.4，最終只獲授 2:1 而非 First。
- 重修課程：**新成績取代舊成績**，但舊成績會喺成績單上標註為"R"（repeated）仍然可見。

## 六、GPA 與內地百分制嘅換算（俾返內地考公／求職參考）

**並無官方換算公式**，但留服認證、HR 實務上常用以下對照：

| HK 4.0 GPA | 百分制（常用換算） | 內地等級近似 |
|------------|-------------------|---------------|
| 4.0 | 95–100 | 優秀 |
| 3.7 | 90–94 | 優秀 |
| 3.3 | 85–89 | 良好上 |
| 3.0 | 80–84 | 良好 |
| 2.7 | 75–79 | 中等上 |
| 2.3 | 70–74 | 中等 |
| 2.0 | 65–69 | 及格 |

**HKU 4.3 制換算**時，唔少 HR 會將 4.3 直接線性映射到 4.0（即除以 4.3 再乘 4.0），亦都有要求成績單後加 HKU 官方「Grading System Explanation」作為佐證。**申請內地體制內崗位時，建議向 HKU 申請開官方 GPA 認證信**，說明 4.3 制同等級對應。

## 七、影響 GPA 嘅關鍵選課同學習策略

1. **唔好淨係揀「好過」嘅水課**：揀水課或者會推高 GPA，但 HKUST 嘅 MCGA 只計專業課，專業課分數唔夠反而會拖低 Major GPA。
2. **Year 1、Year 2 嘅權重好重要**：大部分港校 Year 1–2 每學期 5 科 × 6 學分 = 30 學分，累計約 120 學分，佔畢業總學分一半；GPA 基本盤喺頭兩年已經形成。
3. **慎用 P/F 選項**：HKU 規定 P/F 課程不得超過畢業學分嘅 50%，否則整個學位嘅 Honours 會冇咗。
4. **重修政策**：
   - HKU：F 可重修，新舊成績**都會計入 GGPA**（平均計算）。
   - HKUST：重修新成績**取代**舊成績。
   - CUHK：按科目政策，部分專業重修上限為 2 科。
5. **交流學期**：大部分港校將交流期課程以 P/F 形式回轉，**不計入 GPA**；如想用交流成績推高 GPA，需喺交流前同院系確認政策（少數項目容許以 letter grade 回轉）。
6. **畢業論文 / Capstone**：通常 6–12 學分，畀分亦較為保守；提早搵導師、早起步係避免拖低 GPA 嘅關鍵。

## 八、常見 GPA 誤區逐個擊破

**誤區 1：將 HKU 4.3 當成 4.0 比較**
→ HKU 嘅 3.7 唔等於其他港校嘅 3.7，但榮譽等級要求大致相同。HKU 學生要拎到同等榮譽，實際拎到嘅分數要求稍高（因為頂檔去到 4.3）。

**誤區 2：以為平均 80+ 就穩袋 First Class**
→ 港八大 First 嘅 GGPA 閾值一般 ≥ 3.6，對應大約 A− 嘅整體水平，按百分制 85+ 而唔係 80+。

**誤區 3：忽視「50% letter-graded」規則**
→ 用 P/F 混過通識課係常見策略，但 P/F 比例過高會令整個學位嘅 Honours 消失。

**誤區 4：以為 F 重修乾乾淨淨就冇事**
→ HKU 係「新舊成績都會計入 GGPA」，重修只可以拉高平均，唔可以完全抹走；HKUST 則直接取代，差異極大，必須睇返自己學校嘅規定。

**誤區 5：以為雙主修／雙學位 GPA 獨立計算**
→ 大部分港校**只發一份 GGPA**，覆蓋所有主修；第二主修（Minor）唔會獨立頒榮譽。

## 九、畢業之後：GPA 喺碩士申請同求職入面嘅分量

### 碩士申請（英美港新為主）

| 目標項目 | 典型 GPA 門檻（HK 4.0 制） |
|----------|----------------------------|
| 牛劍 / LSE / IC 頂級碩士 | 3.6+（First Class）|
| UCL / KCL / Edinburgh | 3.3+（2:1）|
| NUS / NTU 熱門碩士 | 3.3–3.5+（2:1）|
| 港大 / 中大 / 科大自家研究型碩士 | 3.3+（2:1，First 更加分）|
| 美國 Top 30 碩士 | 3.5+ |
| 美國 Top 50 碩士 | 3.2+ |

### 求職（以香港為例）

- **投行 / 諮詢 / 四大 Audit**：2:1 係入場券，First 係普遍首輪篩選標準。
- **政府 AO / EO**：唔強制 First，但招聘說明強調 "good honours degree"。
- **科技公司（本地）**：GPA 只係入場，技術能力更重要。
- **中資企業駐港崗位**：傾向睇百分制同學校層級，GPA 有加分但非決定性。

## 十、常見問題 (FAQ)

**Q1：港八大 GPA 唔及格會影響畢業嗎？**
A：唔及格（F）喺大部分學校需要重修通過先可以計入畢業學分，否則達唔到畢業總學分要求。HKU 嘅 F 仲會計入 GGPA 分母，對最終榮譽等級有明顯拖累。

**Q2：申請英國碩士時，港大 GPA 3.5/4.3 算 2:1 定 First？**
A：通常算 **2:1（Upper Second）**。英國院校對港大嘅常見換算：GPA ≥ 3.6/4.3 或 ≥ 3.6/4.0 → First；3.0–3.59 → 2:1。實際以對方 admissions 嘅 "country-specific requirements" 為準。

**Q3：重修之後，成績單會唔會顯示原本嘅 F？**
A：**會**。港八大都係成績單全留痕：舊成績標註為 R（Repeated）/S（Superseded），新成績另列。GPA 計算規則按上文第五節各校邏輯。

**Q4：GPA 同 CGA 係咪同一樣嘢？**
A：概念相同，叫法唔同。HKUST 官方用 CGA（Cumulative Grade Average），HKU／CUHK／PolyU／CityU 多用 GPA／CGPA。對外（碩士申請、僱主）一般統稱 GPA。

**Q5：雙學位（Double Degree）畢業時有幾多個榮譽等級？**
A：通常**只頒一個聯合榮譽**，基於所有課程嘅 GGPA。少數「雙學位雙證」項目（例如港大、科大與海外合辦）會分別頒發兩份證書，榮譽等級獨立計算——以具體項目為準。

**Q6：GPA 嘅 Bell Curve 對 DSE 考生同內地生公唔公平？**
A：港校唔少專業課採用相對評分（class-based curve），當班入面學霸多，A 嘅分數門檻會相應提高。DSE 考生同內地生喺 Year 1 數學／經濟基礎課嘅「內捲度」較高，但去到高階選修課反而會受惠。

**Q7：港校有冇「GPA 保護」機制，例如 Year 1 第一學期唔計 GPA？**
A：**冇通用機制**。只有 HKU Common Core 部分課程可選用 P/F（限額內），HKUST 部分 Year 1 基礎課亦容許學生喺 drop 截止日前轉 P/F。大部分專業課同核心課必須以字母評分。

**Q8：JUPAS 考生同 IB／A-Level 考生嘅畢業 GPA 判定有冇分別？**
A：**冇分別**。入學渠道只影響需唔需要讀 Year 0／先修課；一旦進入本科正課，所有學生嘅 GPA 計算同榮譽判定一視同仁。
