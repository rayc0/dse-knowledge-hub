# 香港八大院校本科生醫療保險與求診全攻略 2026 — 內地學生篇

> 摘要 — 持學生簽證來港的內地本科生，在醫院管理局制度下被界定為「非符合資格人士」(Non-eligible Persons, NEP)，公立醫院收費以接近全成本計算，與本地居民差距可達數十倍(普通住院 HK$5,100/日、急症室 HK$1,230/次)。香港八大院校普遍規定或強烈建議內地生購買學生醫療保險，大部分學校以代收學費方式統一投保，每年保費介乎 HK$800–2,500。本文將逐一梳理入境處的財政能力要求、八大醫保安排、校園診所服務、公私營醫院收費差異、急症處理流程，以及索償時需要注意的細節。

## 一、點解醫療保險唔可以忽視？

香港入境事務處審批學生簽證時，一貫要求申請人證明有足夠財政能力應付整段留學生涯的生活與醫療開支；多間大學更進一步將「投購醫療保險」列為註冊前的強制條件，或者直接代學生投保並計入雜費賬單。

更關鍵的現實是：香港公營醫療實行「雙軌收費制」——持香港身份證的「符合資格人士」(Eligible Persons, EP) 享有大幅公帑補貼；而持學生簽證的內地生一般會被歸類為 NEP，需按接近成本價繳費。以一次闌尾切除手術(住院 5 日連手術)為例，NEP 實際自付額動輒超過 HK$60,000，本地學生卻只須數百港元。

所以話，醫療保險唔係「有就更好、冇都唔緊要」，而係**必須預備的風險防線**。

## 二、醫管局 NEP 收費標準(2024–2025 年度)

根據醫院管理局按《醫院管理局條例》刊憲的收費表，NEP 學生主要項目收費如下(港幣計)：

| 項目 | 本地 EP 收費 | NEP(非本地學生)收費 |
|---|---|---|
| 急症室(A&E)每次 | 180 | 1,230 |
| 普通科門診(GOPC)每次 | 50 | 580 |
| 專科門診首次 | 135 | 1,190 |
| 專科門診覆診 | 80 | 990 |
| 住院(普通科病床)每日 | 120 | 5,100 |
| 日間住院每次 | 120 | 4,680 |
| 私家病床(一等)每日 | — | 11,200 |

> 資料來源：醫管局收費表 Gazette Notice(2024 年 4 月生效)。
> 註：NEP 收費自 2017 年起逐步與成本掛鈎，入院前一般須先繳付按金。

### 按金(Deposit)

NEP 學生入住公立醫院前，須繳交**五日病床費用作為按金**(約 HK$25,500)，出院結賬後多除少補。倘若無醫保或現金不足，有可能被要求先付款後入院。

## 三、八大強制醫保一覽(2025–2026 學年)

各校對非本地生的醫保安排略有差異，但**「統一投保 + 學費代收」**係主流模式。以下整理自八大學生事務處及非本地生入學指引頁面：

| 院校 | 政策類型 | 年保費約數 | 承保機構 / 計劃 |
|---|---|---|---|
| 港大 HKU | 強制統一投保 | HK$800–1,200 | Bupa / Bluecross(學校投標) |
| 中大 CUHK | 強制統一投保 | HK$1,100 | Chubb(Group Medical Plan) |
| 科大 HKUST | 強制統一投保 | HK$1,300 | AXA / Zurich(學校年度投標) |
| 理大 PolyU | 強制統一投保 | HK$1,000–1,500 | AIA / Bluecross |
| 城大 CityU | 強制或自願並需驗證 | HK$1,000 | Bupa(學校方案) |
| 浸大 HKBU | 強制統一投保 | HK$900–1,200 | AXA |
| 嶺大 LingU | 強制統一投保 | HK$1,500 | Zurich / AIA |
| 教大 EdUHK | 強制統一投保 | HK$900 | 學校投標計劃 |

> 以上保費每年隨投標結果浮動，以入學通知書或學生賬單為準。

### 一般保障範圍

- 住院 / 手術費用(年度上限多為 HK$150,000–300,000)
- 急症室 / 門診(部分計劃設限次或限額)
- 意外傷亡 / 個人責任
- 緊急醫療運送 / 遺體運返原居地
- 校內活動、實習、交換期間部分保障

### 常見**不包項目**

- 已存在疾病(Pre-existing conditions)——除非另外加保
- 牙科 / 視光 / 精神科門診(多需額外購買)
- 懷孕 / 生育(併發症除外)
- 整形 / 美容 / 自選疫苗
- 高危運動(攀石、深潛等)——須另行申報

## 五、三大求診情境與建議路徑

### 情境 1：一般感冒、腸胃不適、皮膚痕癢

- **首選**：校內診所或醫務室，收費低，熟悉校園醫保運作
- **次選**：私家普通科診所(GP)，每次 HK$300–500(多包基本藥物)
- **不建議**：直接去公立醫院 GOPC(NEP 收費 HK$580，仲可能要等幾粒鐘)

### 情境 2：非緊急專科問題(扭傷、牙痛、慢性皮膚病)

- 先由校內診所轉介，再去保單網絡內的私家專科
- 使用保險 **Cashless(免墊付)** 網絡可減少先行墊錢
- 牙科、視光通常唔包喺基本計劃內，買之前要睇清楚

### 情境 3：緊急 / 重大疾病或意外

- **即刻打 999** 叫救護車(救護車服務本身免費)
- 最近的公立醫院急症室係最穩陣選擇——設備齊全、24 小時運作
- 入院時出示 **香港身份證 / 簽證 + 醫保卡**，表明「Non-eligible person, full-time student」
- 大部分醫院會致電保險公司確認 **擔保函(Letter of Guarantee, LOG)**；取唔到 LOG 嘅話就要先繳按金

### 建議隨身帶齊

- HKID / 學生簽證頁副本
- 醫保卡 / 保單號碼及 24 小時熱線
- 敏感史 / 長期用藥卡(中英文對照)
- 緊急聯絡人(家長 / 校方國際生事務處)

## 六、需要額外加保嗎？四類建議加保情境

學校統一醫保多屬基礎計劃，以下情況建議自費加購補充險：

1. **住院保障額偏低**：基本計劃年度上限 HK$150,000，對嚴重疾病或大型手術未必足夠，建議將保額調高至 HK$500,000 以上。
2. **有牙科 / 視光 / 精神科需求**：可獨立購買專項附加保障。
3. **經常返內地或出境外遊**：要留意保單嘅 **Geographical coverage**，有需要時加購全球旅遊醫保。
4. **已有病史**：哮喘、糖尿病等需要長期用藥者，要向保險公司書面申報並加保 Pre-existing condition rider。

### 市場常見補充險(2025)

- Bupa Hero / Bupa Global Health Plan
- AIA HealthShield / AIA Overseas Student Plan
- AXA SmartCare / AXA iCare
- Blue Cross Student Protect
- Chubb StudentSafe

年保費介乎 HK$1,500–6,000，視乎保額、墊底費、免墊付網絡而定，購買前務必仔細比較。

## 七、理賠實戰：五步流程

1. **保留所有單據**：醫生處方、費用收據、診斷證明、化驗報告正本。
2. **下載索償表**：大部分保險公司都支援電子索償(Chubb Snap、AXA Emma App、Bupa Hi 等)。
3. **填寫 Claim Form**：須由醫生簽名並蓋診所印章；住院個案要附出院摘要(Discharge Summary)。
4. **留意期限**：一般須於 **30–90 日內** 遞交，逾期可能失效。
5. **跟進賠款**：電子索償大約 7–14 個工作天到賬；複雜個案可能要 4–8 星期。

> 小貼士：大額住院前聯絡保險公司申請 **Pre-authorization + Cashless**，由醫院直接同保險公司結算，可避免一次過墊付幾萬蚊嘅壓力。

## 八、費用實例對照：闌尾炎手術 5 日住院

| 情境 | 粗估費用(HK$) | 學生實際負擔 |
|---|---|---|
| 公立醫院 NEP 全自費 | 60,000–80,000 | 全額自付 |
| 公立醫院 NEP + 基礎校保 | 60,000–80,000 | 超額自付(常見 HK$30,000+) |
| 公立醫院 NEP + 補充高額醫保 | 60,000–80,000 | 保額內近乎 0 |
| 私家醫院自費 | 120,000–200,000 | 全額自付 |
| 私家醫院 + 進階醫保 | 120,000–200,000 | 保額內近乎 0 |

呢組數字最直接講明：**有冇加買補充險，一次住院可以相差 HK$30,000 以上**。

## 九、2026 年政策與趨勢觀察

- **HA NEP 收費續調**：醫管局自 2017 年起逐步將 NEP 收費向成本靠攏，2024 年 4 月先完成近年最大幅度調整；預期 2026 年前後會再次檢討上調。
- **大學集體投標醫保**：大部分院校每 2–3 年公開投標，學生保費會隨市場變動。
- **校外診所網絡擴張**：Bupa / Bluecross 等學生計劃已與港島、九龍多區 GP 及牙醫合作，逐步開通 Cashless 網絡，建議每學年重新下載特約醫生目錄。
- **心理健康逐步納入基本保障**：2024 年後部分大學嘅統一醫保計劃開始涵蓋**有限次數**嘅心理諮詢或精神科門診，留意每年條款更新。

## 十、常見問題(FAQ)

**Q1：學校已經代我買咗醫保，自己仲有冇需要再買？**
A：視乎個人風險承受度。基礎校保足以應付一般求診，但若涉及嚴重疾病、跨境需要、長期用藥，加購補充險會更穩陣。

**Q2：可唔可以用內地嘅商業醫保或城鄉醫保喺香港就醫？**
A：絕大部分內地醫保唔可以直接喺港使用；部分跨境醫保(例如中國平安、友邦中國)支援香港理賠，但要先墊付再拎單據返內地報銷，現金流壓力大。

**Q3：IANG 簽證或畢業後過渡期，學校醫保仲有效嗎？**
A：學校醫保一般只保到畢業當月月底；IANG 期間須自行購買個人醫保。醫管局嘅 NEP 身份喺 IANG 期間同樣適用。

**Q4：打疫苗、洗牙包唔包喺醫保內？**
A：基礎校保通常**唔包**預防性項目(疫苗、體檢、洗牙)。校內診所間中會有免費流感或 HPV 疫苗活動，留意電郵通知。

**Q5：急症後保險未批，醫院追數點算？**
A：向醫院出示醫保卡加在讀證明，請醫院賬務部發信畀保險公司申請 LOG；亦可聯絡學校國際生事務處協助跟進。

**Q6：持學生簽證可唔可以用醫療計劃拎永久居民身份？**
A：唔可以。NEP 轉 EP 身份須取得香港永久性居民身份證(通常連續居港 7 年)，同醫保計劃無直接關係。

**Q7：精神科或心理諮詢包唔包？**
A：大部份基礎計劃**唔包**精神科門診。學校輔導處(Counselling Service)一般免費，複雜個案再轉介私家醫生。

**Q8：返內地期間發病，醫保點用？**
A：睇清楚保單地理範圍。大部分學生醫保覆蓋 **Home country**(內地)嘅緊急醫療，要先墊付後返港索償。
