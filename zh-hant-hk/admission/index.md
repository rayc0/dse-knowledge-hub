# 香港八大院校升學申請全攻略：DSE與高考考生必讀

香港共有八所獲政府資助的學位頒授大學，一般稱為「八大」。所有院校均接受非聯招（Non-JUPAS）途徑的入學申請，無論你是應屆DSE考生、持高考成績的內地學生，還是持其他公開學歷的同學，都可經此途徑直接向心儀院校報名。本文將八大的排名、學費、收生成績、招牌學科及申請時間表一一整理，助你訂立清晰的選校策略。

## 各院校申請重點逐一睇

### 香港大學（HKU）

港大是本地歷史最悠久的綜合研究型大學，醫學、法律、商科、工程等學科均享國際聲譽。Non-JUPAS 競爭非常激烈，每年吸引全球頂尖申請者。

- **參考成績要求：** DSE Best-5 通常需達 **33分或以上**；高考成績則視省份而定，整體需達該省一本線較高分段
- **招牌學科：** 醫學（MBBS）、法律（LLB）、經濟金融（BEcon&Fin）
- **特點：** 全球僱主認受性極高；頭3年保證宿位

### 香港科技大學（HKUST）

科大以理工商科聞名，工程學與商業管理在亞洲處於領先地位。校園坐落西貢清水灣，環境清幽，適合專心學術研究的同學。

- **參考成績要求：** DSE Best-5 一般需達 **30分或以上**；數學及相關理科成績尤其重要
- **招牌學科：** 計算機科學、工程學各系、商學院（HKUST Business School）、EMBA
- **特點：** 創科氛圍濃厚；首年保證宿位

### 香港中文大學（CUHK）

中大是全港唯一設有書院制的院校，實踐中英雙語教學，文科與理科發展均衡。內地高考生可透過「一試兩用」機制，同時以同一張高考成績表申請中大及心儀學科。

- **參考成績要求：** DSE Best-5 一般需達 **30分或以上**；高考（一試兩用）則視學科要求而定
- **招牌學科：** 工商管理（逾九成本科生有交流機會）、醫學、法律、專業會計學
- **特點：** 書院制提供小群體學習體驗；首年保證宿位

### 香港理工大學（PolyU）

理大以實用型專業見稱，設計、酒店及旅遊管理、護理、物理治療等學科全港數一數二，畢業生就業率長期高踞八大前列。

- **參考成績要求：** DSE Best-5 一般需 **25–28分**；熱門學科要求會更高
- **招牌學科：** 設計學院（School of Design）、酒店及旅遊管理、護理學、物理治療
- **特點：** 與業界聯繫緊密；提供部分宿位

### 香港城市大學（CityU）

城大位於九龍塘，校區交通便利。學校在創意媒體、法律、商科及工程等領域實力不俗，並為學生提供大量商界實習機會。

- **參考成績要求：** DSE Best-5 一般需 **24–27分**；個別熱門學科要求更高
- **招牌學科：** 創意媒體、法律、工商管理、電子工程
- **特點：** 地處市區，校外資源豐富

### 香港浸會大學（HKBU）

浸大以人文學科、傳理學（新聞與傳播）、商科及中醫學見長，校園文化深厚，規模較小，師生關係密切。

- **參考成績要求：** DSE Best-5 一般需 **24–27分**
- **招牌學科：** 傳理學院（新聞、電影、廣告公關）、中醫藥學、商學院
- **特點：** 中醫藥學科歷史悠久；傳理學院全港頂尖

### 嶺南大學（LingnanU）

嶺大是香港唯一以博雅教育（Liberal Arts）為辦學核心的大學，班級規模細小，每位學生皆有豐富海外交流機會，師生比例全港最低。

- **參考成績要求：** DSE Best-5 一般需 **22–25分**
- **招牌學科：** 社會科學、人文學科、工商管理（小班教學）
- **特點：** 全方位博雅教育；首年保證宿位

### 香港教育大學（EdUHK）

教大專注於教育專業培訓，是香港培育中小學教師的主要院校，近年積極拓展至社會科學及健康學科。

- **參考成績要求：** DSE Best-5 一般需 **22–25分**
- **招牌學科：** 幼兒教育、小學教育、中學各科教育、特殊教育
- **特點：** 教育專業認受性高；畢業生多投身教育界

| 成績水平 | 選校策略 |

## 申請時間表一覽

| 時段 | 事項 |
|------|------|
| 9–10月 | 各院校公布來年收生資訊，開始研究選校 |
| 10–12月 | Non-JUPAS 網上申請系統開放 |
| 11月–翌年2月 | 提交申請（截止日期各校不同，須逐一查核） |
| 12月–翌年3月 | 部分院校發出面試邀請 |
| 1–3月 | 參加面試（如適用） |
| 3–5月 | 等待條件取錄通知 |
| 4月（第三周） | DSE 公開考試開考 |
| 7月 | DSE 放榜；確認 Firm Choice 取錄 |
| 8–9月 | 註冊入學、申請宿舍、辦理學生簽證 |

> ⚠️ 溫馨提示：以上時間僅作參考。Non-JUPAS 途徑各校截止日期差異頗大（最早 11 月，最遲可延至翌年 5 月），請務必登入心儀院校的非聯招網頁查閱最新日子。

## 申請小貼士

1. **留意課程額外要求：** 部分學科（醫科、法律、建築系等）需要遞交作品集或參與額外考試，面試亦通常為英語進行。
2. **準備英語能力證明：** 不少課程要求 IELTS 或 TOEFL 成績，內地DSE／高考考生宜預早備考。
3. **個人陳述（PS）要度身訂造：** 切忌一份 PS 走天涯；針對每所院校及學科撰寫個人化敘述。
4. **推薦信宜由了解你的老師撰寫：** 推薦內容需具體，能舉出實例佐證你的學術或課外表現。
5. **留意簽證所需文件：** 內地DSE考生獲取錄後，需向入境事務處申辦學生簽證；提早準備住址證明、財力證明等文件。

## 常見問題 FAQ

**Q1. Non-JUPAS 與 JUPAS 途徑有何分別？**
JUPAS 適用於透過香港中學文憑試（DSE）成績申請的本地考生，經統一招生系統處理；Non-JUPAS 則需直接向院校遞交申請，適合非DSE本地生、內地DSE／高考考生及國際課程考生。

**Q2. 八大對內地DSE考生的收生標準是否與本地DSE考生一致？**
收生成績水平大致相若，但非本地生另設有學費較高的資助類別，住宿及獎學金安排亦可能有所不同。

**Q3. 高考考生是否需要同時報考 DSE？**
不需要。八大皆設獨立的高考入學途徑，唯各校要求、計分方式及招生名額不同，請查閱相關院校指南。

**Q4. 申請多間院校會否影響取錄機會？**
不會。Non-JUPAS 不設統一限制，申請者可同時向多所院校遞交申請。
