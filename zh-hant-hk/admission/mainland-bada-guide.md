八間都係 **全英語授課 + 國際化課程**，畢業證書喺內地、海外、香港三地都獲認可。

## 內地生兩條入學路徑

### 路徑 A：Non-JUPAS（非聯招）— 99% 內地生行呢條
- **直接向各大學申請**（唔經 JUPAS 統一招生）
- 憑 **高考成績 + 英語成績**（高考英文 / 雅思 / 托福）
- 部分學系要 **面試**
- 申請期：每年 **10 月開放到翌年 5-6 月**
- 錄取通知：6-7 月

### 路徑 B：JUPAS（大學聯合招生辦法）
- 淨係限 **拎住香港 DSE 成績** 嘅考生
- 內地戶籍學生通常 **唔適用**，除非你喺香港讀 DSE 課程

→ **本文聚焦 Non-JUPAS 路徑**。

## 申請文件清單

1. **學業文件**
   - 高中三年成績單（蓋學校公章 + 翻譯本）
   - 高考成績單（放榜後補交）
   - 高中畢業證

2. **英語證明**（任揀其一）
   - 雅思 6.5+
   - 托福 iBT 80+
   - 高考英文 130/150 以上（部分學校接受）

3. **個人陳述（PS）**
   - 800–1500 字，英文
   - 內容：點解揀呢個學系、相關經歷、未來計劃

4. **推薦信**
   - 一般 1–2 封
   - 由高中老師或社會實踐導師撰寫

5. **課外活動證明**
   - 比賽、義工、研究項目、實習等

6. **面試**（HKU/CUHK/HKUST 必須）
   - 全英文，10–15 分鐘
   - 涵蓋：學術興趣 + 時事觀點 + 未來規劃

## 簽證 + 住宿 + 入境準備

### 學生簽證（Student Visa）

- 攞到 Offer 後由學校代為申請
- 申請人唔使親自去領事館
- 審批時間約 **6–8 週**
- 費用：港幣 230

### 住宿

- **一年級保證宿位**（HKU / CUHK / HKUST / PolyU / CityU 都有提供）
- 二年級起可能要外租 → **建議提早加入學校宿舍輪候名單**

### 銀行戶口 + 八達通

- 入學第一週可以喺校園開戶口（匯豐 / 中銀香港 / 渣打）
- 八達通卡通用於地鐵、巴士同便利店

## 常見失誤（避免中伏）

1. ❌ **淨係等到 5 月高考完先申請** → Non-JUPAS 早輪通道較寬鬆，3 月之前就要交表
2. ❌ **無準備英文面試** → 九成拒信源自面試表現失準
3. ❌ **PS 寫晒自己幾努力** → 應該講「點解揀呢個學系 + 你獨特嘅視角」
4. ❌ **忽略 CUHK 國家統招提前批** → 呢個係內地生最被低估嘅捷徑
5. ❌ **唔申請獎學金** → 大部分獎學金自動評審，但頂尖嘅要額外交文件，錯過即嘥咗幾十萬港幣

## 常見問題 FAQ

**Q：高考失手，仲有冇機會？**
A：有。部分學校接受一本線下 30 分（PolyU / CityU / HKBU），同時睇英語、面試同課外活動綜合表現。

**Q：可以同時申請多間八大嗎？**
A：可以，仲強烈建議。Non-JUPAS 申請之間唔會撞，多報幾間增加機會。

**Q：高考英文未到 130 點算？**
A：補交雅思 / 托福成績。雅思 6.5 普遍接受。

**Q：HKU 同 CUHK 邊間對內地生更友善？**
A：CUHK 行國家統招提前批，流程最簡單；HKU 名氣更大但門檻更高。

**Q：可以轉系嗎？**
A：大一完結可以申請轉系，但要睇 GPA 同學系受歡迎程度。HKU / CUHK 轉商科或法律最難。
