# DSE 英國語文卷三聆聽及綜合卷攻略

香港中學文憑試 (DSE) 英國語文科共設四卷,分別為 Reading、Writing、Listening & Integrated Skills,以及 Speaking。當中 **卷三 (Listening and Integrated Skills)** 佔整科分數 **30%**,考試時間約為 **兩小時**。對於由內地來港升學的同學、國際學校學生,或以英文作為第二語言的考生來說,卷三往往被視為最難應付的一卷——難處並非詞彙或文法本身,而在於它同時測試聆聽理解、資料篩選、整合寫作、時間管理和任務轉換等多項能力,題量大且節奏緊湊。

本文專為正在備試 DSE 英國語文的考生,特別是操普通話背景或對香港課程尚在摸索階段的同學及家長而寫。內容涵蓋考試架構、聆聽訓練方法、Data File 的運用技巧、綜合寫作的通用框架、時間分配策略、常見失分位,以及 2026 年的備試建議。

## 一、卷三考試架構一覽

### 卷別組成

卷三分為 **Part A (Easy Section)** 及 **Part B (Difficult Section)** 兩部分。Part A 為必答,Part B 則須在 **B1 (較淺版本)** 與 **B2 (較深版本)** 之間二擇其一作答。大部分以大學為目標的考生都會選 B2,因為 B2 的最高等級可達 5、5*、5**。

### 考試時長與流程

整卷合共 **兩小時**。聆錄音播放屬固定時段,考生不可自行調節。

| 部分 | 內容 | 建議時間 |
|---|---|---|
| Part A | 聆聽 (錄音播放兩次) + 約 200 字整合寫作 | 約 45 分鐘 |
| Part B | 聆聽 (錄音播放兩次) + 約 400 字整合寫作 | 約 75 分鐘 |

### 評核範疇

卷三同時測試以下能力:

1. **聆聽理解 (Listening Comprehension)** — 摘錄資料、回答問題、識別講者觀點
2. **資料整合 (Integrated Skills)** — 由聆聽材料與 Data File 抽取資訊並加以整理
3. **寫作能力 (Writing)** — 以適當文體 (報告、書信、演辭、發言稿、宣傳文案等) 撰寫
4. **任務意識 (Task Awareness)** — 掌握自身角色、讀者對象及寫作目的

## 二、認識 Data File

**Data File** 是卷三獨有的一份配套資料,厚約二十至三十頁,內容可能包括:

- 新聞報道、海報、單張
- 圖表、統計數據、問卷結果
- 電郵、會議紀錄、訪問摘錄
- 文章、評論、廣告

考生需要在聆聽播放前後,由 Data File 中找出相關內容,配合聆聽材料完成寫作任務。Data File 提供的資訊往往比聆聽部分更豐富,關鍵在於 **快速鎖定所需資料,略過無關段落**。

**重要提示**: Data File 會在考試開卷時一併派發,准許考生 **在聆聽開始前預覽並標記重點**。切勿等到寫作階段才第一次翻閱,否則時間會嚴重不足。

## 三、聆聽部分的應試策略

### 錄音播放規矩

- 每段錄音通常播放 **兩次**
- **首次播放**: 掌握段落主旨及關鍵詞
- **第二次播放**: 核實細節,補回遺漏

### 聆聽前的準備 (Pre-listening)

錄音開始前一般設有兩至三分鐘預讀時間,善用這段時間:

1. **快速閱讀題目要求**,確定每題要填寫的內容 (日期?地點?原因?數字?)
2. **預測答案類型**: 題目若問 "What time?",就重點捕捉時間資料
3. **圈出關鍵詞**: 在題幹上標示 who、what、when、where、why、how
4. **翻閱 Data File 的相關頁面** (時間許可的話)

### 聆聽進行中的要點

- **先掌握大意,再補細節**: 不要死盯某一個詞,否則會錯過後續重點
- **善用縮寫及符號**: 邊聽邊用 K (千)、$ (元)、↑↓ (升降) 等快速記錄
- **留意轉折詞**: "however"、"but"、"actually"、"in fact" 後通常帶有關鍵資料
- **注意數字及專有名詞**: 屬高頻考核位
- **聽不懂先跳過**: 待第二次播放時再設法補回

### 常見聆聽題型

- **直接資訊題**: 時間、地點、價錢、姓名 — 抓得準便得分
- **推斷題**: 講者態度、情感、意圖 — 須聽語氣及關鍵動詞
- **排序題**: 事件先後次序 — 留意 first、then、after that、finally 等連接詞
- **圖表配對題**: 將聽到的資料對應到 Data File 中的圖表
- **句子填充題**: 須按句子的文法結構決定所填詞的詞性

## 四、綜合寫作的通用框架

Part A 與 Part B 皆要求考生根據聆聽材料及 Data File 完成寫作。常見任務類型包括:

- **書信** (致校長、編輯、朋友、市民)
- **報告** (致公司、學校、政府部門)
- **演辭** (校內集會、比賽、公開活動)
- **宣傳文案** (海報、網站、社交媒體帖文)
- **對話或訪問紀錄**

### 落筆前的三個關鍵問題

不論題型,寫作前先答好以下三條:

1. **我是誰?** — 學生?記者?店東?區議員?
2. **寫給誰看?** — 老師?普羅大眾?特定對象?
3. **寫作目的是甚麼?** — 說服?告知?匯報?邀請?投訴?

釐清以上三點,語氣、措辭及結構才能配合「角色感」。閱卷員最重視 **角色一致性** 及 **任務達成度**,並非只計較文法對錯。

### 框架示範:正式書信

```
【正式稱謂】: Dear Principal / Dear Editor / Dear Mr. Chan

【首段: 自報身分及來信目的】
I am writing as the Chairperson of the Student Association to express our concerns about...

【第二段: 重點論點一 + 證據 (取材自聆聽或 Data File)】
Firstly, according to the recent survey conducted by...

【第三段: 重點論點二 + 證據】
Furthermore, the talk delivered by Dr. Wong highlighted...

【第四段: 建議或行動呼籲】
In light of this, we suggest that the school should...

【結尾】: Yours faithfully / Yours sincerely + 署名
```

### 框架示範:演辭

```
【開場】: Good morning, everyone. My name is... and today I would like to speak about...

【背景引入】: Recently, our school has been facing...

【論點段落】: First of all... / Secondly... / Moreover...

【行動呼籲】: Therefore, I urge each of you to...

【結束】: Thank you for your attention.
```

### 框架示範:報告

```
【標題】: Report on [Topic]
【To】: [收件人]
【From】: [你的角色]
【Date】: [日期]

1. Introduction: The purpose of this report is to...
2. Findings: 由聆聽材料及 Data File 取得的事實與數據
3. Analysis: 闡釋以上發現的意義
4. Recommendations: 因應分析提出建議
5. Conclusion: 撮要核心觀點
```

## 五、兩小時時間分配參考

| 時段 | 任務 |
|---|---|
| 0:00 - 0:03 | 細閱答題指示,快速翻看 Data File 目錄 |
| 0:03 - 0:08 | 預讀 Part A 題目,標記 Data File 相關頁 |
| 0:08 - 0:20 | Part A 聆聽 (錄音播放兩次) |
| 0:20 - 0:40 | Part A 寫作 (約 200 字) |
| 0:40 - 0:45 | 預讀 Part B 題目及 Data File |
| 0:45 - 1:05 | Part B 聆聽 (錄音播放兩次) |
| 1:05 - 1:50 | Part B 寫作 (約 400 字) |
| 1:50 - 2:00 | 通篇檢查 (串字、文法、漏答) |

**請注意**: 錄音播放時間固定,考生只能調節其餘時段的分配。

## 六、常見扣分陷阱

### 文法與串字

- **時態混亂**: 匯報過去事件用過去式、談及計劃用將來式、描述現況用現在式——切忌亂跳
- **主謂一致**: 例如 "The student as well as the teachers is/are..." 屬典型陷阱
- **冠詞遺漏**: the、a、an 運用不當,是母語與非母語考生的明顯分野
- **串字出錯**: 即使是常用字,串錯亦會失分——常見出錯字:receive、separate、necessary、definitely
- **標點符號**: 受中文影響容易漏掉英文句號

### 內容與任務

- **角色混淆**: 寫給校長卻用朋友傾偈的語氣
- **照抄原文**: 直接複製 Data File 原句——閱卷員視之為 "lifting",會大幅扣分
- **任務未完**: 題目要求寫三點,結果只寫兩點
- **忽略讀者**: 運用讀者未必理解的術語或縮寫
- **結構模糊**: 一大段文字從頭到尾,毫無分段

### 聆聽方面

- **錯失關鍵資訊**: 未有捕捉數字、姓名、日期
- **浪費預讀時間**: 錄音響起時仍未讀畢題目
- **錯過第二次機會**: 第一次聽不懂便放棄,沒有善用重播

## 七、非本地考生的額外挑戰

### 口音適應

DSE 聆聽錄音採用 **英式或港式英語發音**,與內地或美式英語有別。常見適應要點:

- **母音**: 英式 "can't" 讀 /kɑːnt/,美式讀 /kænt/
- **詞尾 r**: 英式一般不發音 (car → /kɑː/)
- **語速**: 日常對話偏快,新聞報導偏慢
- **語調**: 起伏較普通話明顯,節奏感強

**訓練建議**: 每日收聽 BBC News、TED Talks (英式講者)、香港電台英文節目,或 DSE 歷屆試題錄音。至少需要 **二十小時** 的針對性英式聆聽訓練。

### 中式英文思維

內地背景考生常見毛病:

- 直譯中文,造成語法錯誤 (如 "Many peoples think that..." 而非 "Many people think that...")
- 濫用 "very" (應改用更精準的形容詞,如 "exceptionally"、"particularly")
- 句式過於單調 (全文皆是簡單句,缺乏複合句及從句)
- 論點太直白 (英文議論文較常用數據及例證說服,少用情感呼籲)

### 語域意識

英文寫作對 **formal / informal / neutral** 的劃分較中文嚴謹。DSE 閱卷員會扣分的語域錯誤:

- 致校長的書信卻寫 "I wanna" 而非 "I would like to"
- 正式報告出現 "stuff" 而非 "items" 或 "matters"
- 演辭中突然冒出 "kinda" 或 "gonna"

## 八、Level 4、5、5*、5** 的分水嶺

DSE 英國語文卷三的等級大致可作以下區分:

| 等級 | 整體表現 |
|---|---|
| **Level 4** | 基本完成任務,文法正確率約七至八成,資料抽取合理,結構清晰 |
| **Level 5** | 任務完成度高,文法近乎零錯,詞彙具一定變化,結構完整 |
| **Level 5*** | 用詞精準,句式多變,角色感強,能批判地運用資料 |
| **Level 5**** | 語言接近母語水平,論點深入,具個人風格及創意 |

由 5 進軍 5** 的關鍵,並非堆砌字數,而在於 **每句話的質素**。一篇結構清晰、用詞精準、角色鮮明的 300 字文章,往往比一篇文法零亂、堆砌辭藻的 500 字文章得分更高。

## 九、九十日備考計劃

### 第一至三十日 (基礎鞏固期)

- **聆聽訓練**: 每日三十分鐘英式英語聆聽 (BBC 6 Minute English 為入門好材料)
- **詞彙累積**: 每日二十個學術詞彙 (報告、書信、演辭常用)
- **文法重溫**: 重點複習時態、被動句、從句
- **試題研習**: 完成一至兩份 Part A 真題,熟悉題型

### 第三十一至六十日 (綜合訓練期)

- **完整試卷**: 每週完成一至兩份完整卷三,嚴格計時
- **錯題簿**: 記錄每次聆聽及寫作的失誤,分類整理
- **樣本研讀**: 細閱香港考評局公開的 Level 5** 樣卷
- **模擬寫作**: 每週撰寫三至四篇不同文體的作文,邀請老師或同學批改

### 第六十一至九十日 (衝刺調整期)

- **集中攻堅**: 完成近五年試題,分析考核趨勢
- **時間管理**: 嚴格按照考試節奏操練
- **身心調整**: 避免熬夜,保持作息穩定
- **考前一周**: 只重做已操練過的題目,鞏固信心,不宜再嘗試新題型

## 十一、結語

卷三屬 DSE 英國語文科中最考驗綜合能力的一卷——它不只測試你懂不懂英語,更測試你能否在高壓限時下,由多源資訊中迅速抽取、整理並重組,再以恰當語言向指定讀者呈現。對非本地考生而言,這卷講究 **系統性訓練**,單靠死記硬背難以攻克。由聆聽、詞彙、文法到寫作框架,每一環皆可透過明確練習逐步提升。

如果你正備戰 2026 年 DSE,請緊記:卷三的成績並非臨考前一個月衝刺而來,而是依靠數月的每日累積及大量試題操練。**保持穩定節奏、由錯誤中學習、模擬真實考試環境**,定會見到自己的進步。
