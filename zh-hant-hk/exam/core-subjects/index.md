# DSE四大必修核心科深度拆解

香港中學文憑考試（HKDSE）設有四個必修核心科目（Core Subjects），無論本地生抑或自修生均須報考。這四科的成績，是JUPAS大學聯招收生的計算基石，亦是非聯招（Non-JUPAS）途徑入學的內地學生最常以DSE成績作申請的核心指標。本文將逐科拆解各科特色、等級分佈與備考要點。

## 一、中國語文（Chinese Language）

### 科目概覽

中文科被公認為DSE中最難駕馭的核心科之一，亦是內地生最常「失手」的科目。考核模式分為四卷：

- **卷一：閱讀能力**（佔全科30%）：文言文與白話文篇章並重，須理解、分析以至評價文章
- **卷二：寫作能力**（佔全科30%）：實用文（書信、報告、建議書等）以及議論文／記敘文
- **卷三：聆聽及綜合能力**（佔全科20%）：聆聽錄音後撰寫摘要或綜合報告
- **卷四：說話能力**（口試，佔全科20%）：小組討論形式進行

### 重要提示：口試須以粵語應考

中文口試**必須以粵語作答**，這是內地學生最大的樽頸。普通話母語者若粵語表達不夠流利，往往在口試失分甚多。建議提早數年開始接觸粵語，或針對口試題型進行密集式操練。

### 等級分佈（每年約五萬名考生）

| 等級 | 百分比 | 估算人數 |
|------|--------|----------|
| 5** | 2–3% | 1,000–1,500 |
| 5* | 5–6% | 2,500–3,000 |
| 5 | 8–10% | 4,000–5,000 |
| 4 | 15–18% | 7,500–9,000 |
| 3 | 20–22% | 10,000–11,000 |
| 2 | 20–22% | 10,000–11,000 |
| 1或以下 | 約25% | 12,500+ |

### 大學收生最低要求

- 大部分學士課程：**Level 3**
- 中文相關學科（如中文系、教育學院）：**Level 4–5**
- 部分國際課程或特殊專才收生通道，或可獲豁免中文要求

### 備考建議

- 大量閱讀粵語白話文報章及文言經典，熟習本港書面語體系
- 寫作卷必須掌握實用文格式，包括書信抬頭、結尾敬語等固定範式
- 口試宜提前練習粵語表達，並熟悉小組討論常見議題（社會時事、價值觀思辨等）

## 二、英國語文（English Language）

### 科目概覽

英文科往往是影響內地生入學結果最關鍵的一科。絕大多數香港大學課程均要求英文達**Level 4或以上**。考核分為四卷：

- **卷一：閱讀**（25%）：涵蓋不同文體的理解題
- **卷二：寫作**（25%）：功能性寫作（電郵、建議書等）及延伸寫作（議論文、故事創作）
- **卷三：聆聽及綜合**（25%）：聆聽後摘錄要點、撰寫摘要或回答問題
- **卷四： Speaking（口語）**（25%）：小組討論與個人短講，全程英語進行

### 等級分佈

| 等級 | 百分比 |
|------|--------|
| 5** | 約2% |
| 5* | 約5% |
| 5 | 約10% |
| 4 | 約18% |
| 3 | 約22% |
| 2 | 約22% |
| 1或以下 | 約21% |

### 大學收生最低要求

- 大部分大學課程：**Level 3–4**（Level 3僅為最低門檻，熱門學科普遍要求Level 4以上）
- 港大、科大等頂尖商科及理工課程：通常要求 **Level 4–5**
- 英文系、翻譯等以英文授課為主的學科：**Level 5或以上**

### 備考建議

- DSE英文側重實用及批判性寫作，與內地英語考核風格有別，建議多閱讀香港英文報章（如South China Morning Post）
- 口試須熟習討論流程——提出論點、回應他人、歸納總結——而非單純追求語言流暢
- 寫作卷須掌握不同文體格式：商業書信、報告、網誌等各有固定結構

## 三、數學（Mathematics）

### 科目結構

數學科分為兩大部分：

**必修部分（Compulsory Part）**——所有考生必須應考

- 涵蓋代數、數列、函數、統計、概率、幾何、三角函數等
- 共兩份試卷，考試時間合共約三小時
- 整體難度中等，但對拉開分數差距作用顯著

**延伸單元（Extended Module）**——選修部分，可分開報考

- **M1（微積分與統計）**：適合商科、生命科學等方向
- **M2（代數與微積分）**：適合理工科、數學系方向，難度較M1更高

延伸單元成績獨立計算，部分大學（尤其科大、理大的工程類學科）會將M1/M2列為收生要求或加分條件。

### 等級分佈（必修部分）

| 等級 | 百分比 |
|------|--------|
| 5** | 約3–4% |
| 5* | 約6% |
| 5 | 約10% |
| 4 | 約16% |
| 3 | 約18% |
| 2 | 約20% |
| 1或以下 | 約27% |

數學必修部分取得5**的比例相對較高，是理科生「摘星」的重要戰場。

### 大學收生要求

- 文科／社科：一般要求 **Level 2–3**
- 商科（如工商管理、會計）：一般要求 **Level 3–4**
- 理工科：要求 **Level 4**，部分課程更要求M2達 **Level 3** 以上

### 備考建議

- DSE數學評分重視完整解題步驟，單寫答案是不足夠的
- M2內容與內地高中數學選修模塊有不少重疊，內地理科生通常較有優勢
- Past Papers（歷年試卷）是最有效的備考工具，建議完成最少近五年完整試卷

## 四、公民與社會發展科（CSD）

### 2021年課程改革背景

這是四科之中變化最大的一科。原「通識教育科」（Liberal Studies）於2021年改革為「公民與社會發展科」，課程內容與評核方式均有重大調整：

**主要改動：**

- 刪減具爭議性的批判議題辯論
- 新增「國家發展」及「當代中國」專題
- 評核方式由公開考試改為**校本評核（SBA）**及**考察活動報告**
- 內地考察（大灣區或其他城市）成為課程核心組成部分

### 科目主題（2021年起）

| 主題 | 主要內容 |
|------|----------|
| 主題一：香港社會 | 本港歷史、身份認同、社會發展 |
| 主題二：國家發展 | 國家成就、「一國兩制」、香港與國家關係 |
| 主題三：當代世界 | 全球議題、可持續發展、國際關係 |

### 等級與評核

- CSD採用「**達標／未達標（Attained / Not Attained）**」評級，**不設1–5**等數字等級
- 大學收生時，該科**不計入「最佳五科」或「最佳六科」**分數計算，但須達到「Attained」
- 極少數學生會因CSD未達標而影響入學

### 對內地生的影響

以Non-JUPAS途徑申請的內地學生，若未曾在香港中學就讀，一般**毋須提交CSD成績**，可以其他科目成績作申請。不過，在本港中學就讀的學生則必須完成此課程並達標。

## 四科綜合策略一覽

| 科目 | 內地生難度 | 策略重點 |
|------|------------|----------|
| 中國語文 | ★★★★★（最難） | 提早學粵語、大量操練寫作 |
| 英國語文 | ★★★☆☆（中等） | 多閱讀英文報章、密集練習口試 |
| 數學 | ★★☆☆☆（內地理科生佔優） | 操練歷年試卷，選修M2提升競爭力 |
| CSD | ★☆☆☆☆（Non-JUPAS一般不計） | 在港就讀者按課程要求達標即可 |

### 整體策略建議

四科之中，**英文成績往往是決定內地生能否入讀頂尖大學的關鍵**。數學科方面，內地理科生普遍具備優勢；中文科則是最大障礙，宜提早部署。對於以Non-JUPAS途徑報考的內地學生，CSD影響有限，但中、英、數三科的表現直接關乎入學機會，建議根據自身強弱項作針對性準備。
