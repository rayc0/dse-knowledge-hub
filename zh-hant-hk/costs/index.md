# 嚟香港讀書使幾錢？八大院校學費、住屋、生活費全攻略

香港八大嘅學費比起英美頂尖大學低唔少，但對內地家庭嚟講，仍然係一筆唔細嘅開支。成個學年計落嚟，連學費、住宿同日常使費，大致要預二十幾萬港元落四五十萬港元不等，視乎你揀邊間學校、住邊區、過咩生活。本頁幫你逐項拆解八間院校嘅收費、住宿選擇同實際生活成本，等你可以喺申請前就做好預算。

## 八大院校學費一覽（2024/25 學年）

香港八間大學資助院校嘅非本地本科生學費，經政府統一資助後，基本上都係同一個價位，但個別學科會額外收取附加費：

| 院校 | 標準學費（非本地生） | 備註 |
|------|------|------|
| 香港大學（HKU） | HK$145,000／年 | 醫科 MBBS 約 HK$261,000 |
| 香港科技大學（HKUST） | HK$145,000／年 | — |
| 香港中文大學（CUHK） | HK$145,000／年 | — |
| 香港理工大學（PolyU） | HK$145,000／年 | 部分專業另加附加費 |
| 香港城市大學（CityU） | HK$145,000／年 | — |
| 香港浸會大學（HKBU） | HK$145,000／年 | — |
| 嶺南大學（LingnanU） | HK$145,000／年 | — |
| 香港教育大學（EdUHK） | HK$145,000／年 | — |

**匯率參考（2025 年約數）：**
- HK$145,000 ≈ 人民幣約 13.5 萬元（實際視乎匯率浮動）

醫科同牙科等專業課程嘅學費差距比較大，例如港大醫科一年就接近 HK$261,000，呢點要特別留意。如果想睇更細嘅分項，可以參考我哋嘅 [大學費用詳細指南](/zh-hant-hk/costs/university-fees/)。

## 住宿費用點樣揀？

香港讀書，住宿係成個 budget 入面最唔穩定嘅一環。你可以揀住宿舍（Hall），又或者出嚟自己租樓。兩者嘅價錢同體驗差距都幾大。

### 大學宿舍（Hall / Hostel）

宿舍通常係內地新生第一年嘅首選，價錢相對固定，又容易融入校園生活：

| 院校 | 宿舍費（參考） | 房型及特色 |
|------|------|------|
| HKU | HK$16,000–25,000／年 | 雙人房至單人房 |
| HKUST | HK$18,000–28,000／年 | 雙人房至單人房 |
| CUHK | HK$14,000–22,000／年 | 書院制，環境開揚 |
| PolyU | HK$20,000–30,000／年 | 市區校園，空間較細 |
| CityU | HK$22,000–30,000／年 | 市區校園，設施較新 |
| HKBU | HK$16,000–24,000／年 | 部分宿舍喺九龍塘 |
| LingnanU | HK$16,000–22,000／年 | 保證首年宿位 |
| EdUHK | HK$14,000–20,000／年 | 大埔校園 |

### 校外租樓

如果抽唔到宿舍，或者想住得自在啲，好多同學會選擇喺學校附近租樓。香港租樓分為幾類：劏房、套房、共居公寓（Co-living），價錢可以差好遠：

| 區域 | 月租參考（劏房／套房） | 交通方便程度 |
|------|------|------|
| 沙田、大圍（近 CUHK） | HK$4,000–7,000 | 良好，有屯馬綫 |
| 清水灣、將軍澳（近 HKUST） | HK$5,000–8,000 | 一般，要靠小巴或校巴 |
| 港島西環（近 HKU） | HK$6,000–10,000 | 極佳 |
| 九龍塘、石硤尾（近 HKBU／CityU） | HK$5,000–8,000 | 良好 |
| 屯門、元朗（近 EdUHK／LingnanU） | HK$3,500–6,000 | 尚可，輕鐵覆蓋 |

> 小貼士：屯門、元朗一帶租金最平，但上學車程可能接近一個鐘頭。如果你打算每日返學，要將交通費都計埋入 budget。

## 一年生活費要預幾多？

以下係非宿舍生嘅每月開支估算（港元）：

| 開支項目 | 每月估算 | 一年估算 |
|----------|----------|----------|
| 住宿（校外平均） | HK$5,000–7,000 | HK$60,000–84,000 |
| 飲食 | HK$3,000–5,000 | HK$36,000–60,000 |
| 交通（八達通） | HK$800–1,500 | HK$9,600–18,000 |
| 書簿同文具 | HK$300–600 | HK$3,600–7,200 |
| 電話同網絡 | HK$200–400 | HK$2,400–4,800 |
| 衣物、娛樂 | HK$500–1,500 | HK$6,000–18,000 |
| 醫療（基本） | HK$100–300 | HK$1,200–3,600 |
| **每月合計** | **HK$9,900–16,300** | **HK$118,800–195,600** |

### 宿舍生生活費參考

如果抽到宿舍，生活成本會大幅下降，因為住宿同膳食（部分書院或宿舍有飯堂）已經包含喺入面：

| 開支項目 | 每月估算 | 一年估算 |
|----------|----------|----------|
| 住宿（宿舍攤分） | HK$1,500–2,500 | HK$18,000–30,000 |
| 飲食（含飯堂） | HK$2,500–4,000 | HK$30,000–48,000 |
| 交通 | HK$600–1,200 | HK$7,200–14,400 |
| 書簿及其他 | HK$500–1,000 | HK$6,000–12,000 |
| **每月合計** | **HK$5,100–8,700** | **HK$61,200–104,400** |

## 獎學金可以慳幾多？

如果成績夠好，可以透過獎學金大幅減輕負擔。香港八間大學同政府都有唔同類型嘅獎學金供內地生申請：

### 各院校獎學金

| 院校 | 主要獎學金 | 資助額參考 |
|------|------|------|
| HKU | HKU Scholarship／許士芬獎學金 | 全額學費至數萬港元 |
| HKUST | HKUST Scholarship | 全額至部分學費 |
| CUHK | CUHK Scholarship／廖偉榮紀念獎學金 | 全額至部分學費 |
| PolyU | PolyU Presidential Scholarship | 全額至部分學費 |
| CityU | CityU Scholarship | 全額至部分學費 |
| HKBU | HKBU Scholarship | 部分學費 |
| LingnanU | President's Scholarship | 部分學費 |

**申請須知：** 大部分獎學金需要喺入學申請時一齊遞交，或者由院校喺錄取後主動提名，記得留意各校官網嘅截止日期同具體要求。

### 政府及社會獎學金

- **香港賽馬會獎學金** — 全面資助學費同生活津貼
- **內地省級政府赴港獎學金** — 部分省份有提供，金額不一
- **企業贊助獎學金** — 個別企業或機構贊助，要自行查詢

想知更多申請細節，可以參考 [香港大學獎學金申請指南](/zh-hant-hk/costs/scholarships-guide/)。

## 學生貸款同融資途徑

內地生一般唔符合香港政府學生資助計劃（HKSL）嘅申請資格，但都有其他途徑：

- 部分院校設有緊急助學金，供突發經濟困難嘅學生申請
- 部分內地銀行提供留學貸款產品，專門畀赴港升學嘅學生

詳細資訊可以睇 [學生貸款與融資指南](/zh-hant-hk/costs/student-loans-and-financing/)。

## 財務規劃實用建議

1. **預留匯率緩衝**：港元同人民幣匯率會浮動，建議年度預算上加多 10–15% 緩衝，比較穩陣
2. **宿舍優先**：第一年申請宿舍可以大幅降低生活成本，亦容易融入校園圈子
3. **獎學金唔好懶**：申請時記得完整填寫獎學金申請表，好多學生因為漏咗一步而錯失機會
4. **提早開戶**：到港前了解香港銀行開戶要求，可以參考 [銀行開戶指南](/zh-hant-hk/admission/bank-hkid-octopus-sim-setup-guide-2026/)
5. **醫療保險**：確認自己嘅醫療保險覆蓋範圍，各校學生保險嘅保障內容都唔同
6. **八達通同電話卡**：提早準備八達通同本地電話卡，生活上會方便好多
