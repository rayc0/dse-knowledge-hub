# 香港大學理學科完全攻略——DSE考生及內地生適用

理學（Science）是香港頂尖大學中科研實力最為突出的學科群之一。香港科技大學、香港大學和香港中文大學的理學院，在物理、化學、生命科學等領域發表大量國際頂級論文，為有志投身科研或學術事業的DSE同學和內地學生提供了極具競爭力的升學平台。本文將從課程概覽、科研出路、博士路徑、DSE選科策略到獎學金逐一拆解，助你規劃未來。

## 一、三大學理學院課程速覽

### 1.1 香港科技大學（HKUST）——理學院（School of Science）

| 課程 | 重點方向 |
|---|---|
| 物理學（Physics） | 凝聚態物理、量子物理、天體物理 |
| 化學（Chemistry） | 藥物化學、納米材料、綠色化學 |
| 生物化學及細胞生物學（Biochemistry & Cell Biology） | 細胞生物學、分子遺傳學、腦神經科學 |
| 數學（Mathematics） | 純數學、應用數學、數據科學 |
| 海洋科學（Ocean Science） | 海洋生態、氣候變化、海洋地質 |

**科研亮點：**
- HKUST 物理系與諾貝爾物理學獎得主淵源深厚；多位頂尖物理學者坐鎮，量子材料、拓樸物理等前沿研究位處亞洲前列
- 與中科院多個研究所簽訂聯合研究協議，內地生參與科研機會豐富

### 1.2 香港大學（HKU）——理學院（Faculty of Science）

| 課程 | 重點方向 |
|---|---|
| 生物化學（Biochemistry） | 蛋白質結構、基因組學、癌症生物學 |
| 生物學（Biology） | 生態學、演化生物學、海洋生物 |
| 化學（Chemistry） | 有機合成、計算化學、藥物開發 |
| 地球科學（Earth Sciences） | 地質學、氣候科學、自然災害 |
| 數學（Mathematics） | 偏微分方程、數論、概率論 |
| 物理學（Physics） | 理論物理、天體物理、量子信息 |
| 統計學（Statistics） | 生物統計、金融統計、機器學習 |
| 環境科學（Environmental Science） | 大氣科學、水文學、污染控制 |

**特色：**
- HKU 理學院與李嘉誠醫學院協作緊密，生命科學方向科研實力雄厚
- 與香港天文台、漁農自然護理署等政府機構合作研究，實戰數據多

### 1.3 香港中文大學（CUHK）——理學院（Faculty of Science）

| 課程 | 特色 |
|---|---|
| 生物化學（Biochemistry） | 中醫與現代生化結合，研究角度獨特 |
| 化學（Chemistry） | 材料化學、界面科學 |
| 地球系統科學（Earth System Science） | 氣候變化、遙感技術 |
| 數學（Mathematics） | 應用數學強（特別是金融數學） |
| 物理（Physics） | 表面科學、磁性材料 |
| 生命科學（Life Sciences） | 跨學科整合培訓 |
| 統計學（Statistics） | 生物統計、經濟統計 |

**特色：**
- 書院制學習社群，理科生可參與大量跨院系活動
- 中醫研究國際認可，與生命科學形成獨特交叉優勢

## 二、學科細分與出路

### 2.1 物理學（Physics）

| 分支方向 | 研究內容 | 就業／升學出路 |
|---|---|---|
| 凝聚態物理 | 超導體、量子材料、納米結構 | 學術研究、半導體行業 |
| 量子信息 | 量子計算、量子密碼 | 科技企業、國家實驗室 |
| 天體物理 | 宇宙學、黑洞、引力波 | 學術研究為主 |
| 計算物理 | 數值模擬、高效能運算 | 量化金融、氣候模型 |

### 2.2 化學（Chemistry）

| 分支方向 | 研究內容 | 就業出路 |
|---|---|---|
| 有機化學 | 新藥合成、天然產物 | 藥企研發、醫療器械 |
| 無機／材料化學 | 功能材料、催化劑 | 材料公司、新能源 |
| 分析化學 | 儀器分析、食物安全檢測 | 食品／環境檢測機構 |
| 計算化學 | 分子模擬、藥物設計 | AI 藥物發現公司 |

### 2.3 生命科學（Biology / Biochemistry）

| 分支方向 | 研究內容 | 就業出路 |
|---|---|---|
| 分子生物學 | DNA 複製、基因表達、基因編輯 | 生物科技公司、基因檢測 |
| 細胞生物學 | 幹細胞、癌症機制 | 藥企研發、醫院研究部 |
| 生態學 | 生物多樣性、環境變化 | 環保機構、政府部門 |
| 微生物學 | 病毒學、抗生素研究 | 公共衛生、生物安全 |

### 2.4 環境科學（Environmental Science）

香港的環境科學課程結合大量本地議題：
- 珠三角空氣污染監測（與粵港科研合作密切）
- 南中國海海洋生態研究
- 城市熱島效應與氣候政策

- HKUST 物理學者長期在凝聚態物理、量子材料領域貢獻卓著
- 多位 HKUST 物理教授為美國物理學會會士（APS Fellows）
- 與 MIT、UC Berkeley 等頂尖學府設有聯合研究項目

## 四、本科後的博士與學術路徑

### 4.1 典型進修階梯

```
BSc（4 年）
   ↓
MPhil / MSc（1—2 年）  ← 香港各大學
   ↓
PhD（3—5 年）          ← 香港／英美頂尖大學
   ↓
博士後（2—3 年）        ← 國際流動
   ↓
學術職位（助理教授起步）
```

### 4.2 香港博士研究的優勢
- 香港博士生每月可獲約 **HKD 18,000—20,000** 的研究生獎學金（研究資助局 RGC 資助）
- 香港研究生學位獲英美全球頂尖大學認可
- 與內地科研合作密切，可在兩地實驗室之間流動

### 4.3 直接申請海外博士
- 持有香港頂尖大學 BSc 學位，可直接申請 MIT、史丹福、劍橋等頂尖博士
- HKUST 物理、化學方向學生成功獲海外頂尖博士取錄的比例甚高

## 五、DSE 理科選科組合全攻略

### 5.1 各專業最佳組合

| 目標專業 | 最佳 DSE 組合 | 原因 |
|---|---|---|
| 物理學 | 物理＋數學 M2＋化學 | 物理為核心，M2 提供微積分基礎 |
| 化學 | 化學＋物理＋數學 M2 | 化學為核心，物理數學互補 |
| 生物化學 | 化學＋生物＋物理 | 三科並重，有機化學基礎必備 |
| 生物學 | 生物＋化學＋物理／地理 | 生物為核心，化學作輔助 |
| 環境科學 | 生物＋地理＋化學 | 地理提供地球系統視角 |
| 數學 | M1 或 M2＋物理（甚或經濟） | 數學基礎最關鍵 |

### 5.2 聯合科學（Combined Science）要留神
- DSE 提供聯合科學選項：物理＋化學 或 生物＋化學
- 聯合科學只佔 1 個選修科位置，但通常被頂尖大學視為等同 1 個科目
- **建議**：有志入讀 HKUST／HKU 理學院者，應盡量分開報考獨立科目（獨立物理＋獨立化學），而非聯合科學；分開報考在計分彈性上明顯佔優

### 5.3 DSE 理科計分小貼士
- 物理、化學、生物、數學 M1/M2 同屬選修科 A 類別，校內評核佔 20%、公開試佔 80%
- 想入讀 HKUST 理學院穩陣計，最好 3 科選修總分達 **24 分或以上**（5\*\*=7、5\*=6、5=5、4=4）
- 英文達 **Level 5** 或以上，會獲部分學系優先考慮

## 六、內地生獎學金一覽

### 6.1 主要獎學金

| 獎學金 | 院校 | 金額 |
|---|---|---|
| HKUST 本科獎學金（內地生） | HKUST | 全額學費＋生活津貼 |
| HKU 入學獎學金計劃 | HKU | 全額或部分資助 |
| CUHK 全額獎學金 | CUHK | 全額學費＋生活補貼 |
| 香港博士獎學金計劃（HKPFS） | 全港博士生 | 每月 HKD 26,900＋會議津貼 |

### 6.2 內地理科生加分位
- 內地理科生在數學和自然科學的 DSE 成績一般較高，有助獎學金申請
- 曾參加**全國中學生物理／化學／生物奧林匹克競賽**並獲獎的同學，在大學申請及獎學金評審中具明顯優勢
- 部分獎學金設有面試或學術評核，宜提早準備個人陳述（Personal Statement）及學術履歷

## 七、香港 vs 內地頂尖理科院校

| 比較維度 | 香港（HKUST／HKU／CUHK） | 清華大學理學院 | 中國科技大學（USTC） |
|---|---|---|---|
| QS 自然科學排名 | 全球 70—120 名 | 全球 20—40 名 | 全球 40—80 名 |
| 國際化程度 | 極高（全英文教學） | 中等（部分英文） | 較低（以中文為主） |
| 科研經費 | 中等（港府 RGC 資助） | 高（國家重點資助） | 高（國家重點資助） |
| 諾貝爾獎聯繫 | HKUST 物理有學術淵源 | 無直接聯繫 | 無直接聯繫 |
| 海外升博認受性 | 極高 | 高 | 高 |
| 本科生科研機會 | 豐富（UROP 等項目） | 豐富 | 極豐富（科研為本） |
| 學費（內地生） | 約 HKD 14 萬／年 | 約 RMB 5,000／年 | 約 RMB 5,000／年 |
| 生活费 | 高（香港生活指數） | 中等 | 較低 |

**香港理科三大賣點：**
1. 全英學術訓練，海外深造大幅佔優
2. 與國際頂尖科學家近距離合作（很多香港大學教授畢業或曾任教於海外頂尖學府）
3. 大灣區科研走廊：與深圳科創產業近在咫尺，實習與就業選擇多

## 八、AI 時代的理科新出路

| 趨勢 | 對理科生的影響 |
|---|---|
| AI＋生命科學 | 生物信息學、AI 藥物發現需要「生化＋計算機」雙背景 |
| 量子計算商業化 | 物理背景人才在量子計算企業極為搶手 |
| 可再生能源 | 化學／材料畢業生在新能源（電池、光伏）前景廣闊 |
| 氣候科學 | 環境科學＋大數據＝氣候模型研究新需求 |

香港頂尖大學正積極推出**跨學科雙主修**（例如「物理＋計算機」、「生物化學＋數據科學」），DSE 理科生可善用這些靈活課程設計，提升跨界競爭力。

## 十、給 DSE 同學與內地生的貼士

1. **DSE 選科鎖定三科理科**：物理、化學、生物中起碼選兩科，並強烈建議加報數學 M2，否則進 HKUST 物理／數學系會較吃力
2. **英文卷不可忽視**：香港大學全英授課，DSE 英文 Level 3 或以下將難以跟上學習節奏
3. **早規劃科研經歷**：中四、中五起嘗試參與校內科研計劃、科學比賽或師長的研究項目，撰寫 Personal Statement 時會更立體
4. **內地生要留意簽證**：以內地生身份入讀本科需持有往來港澳通行證及相關學生簽證，開學前必須辦妥
5. **獎學金截止日期**：HKUST、HKU、CUHK 的入學獎學金申請通常與入學申請同步截止，逾期不予受理

## 十一、總結

香港頂尖大學理學院為 DSE 考生及內地學生提供了全球認可的國際化科學教育平台。英文學術訓練與富的科研機會，令畢業生在海外博士申請中佔盡優勢：

- **HKUST**：物理及化學科研實力最為突出，量子材料、凝聚態物理處於亞洲領先位置
- **HKU**：生命科學與醫學院協同優勢明顯，地球與環境科學資源豐富
- **CUHK**：跨學科理科教育獨具特色，數學及金融數學方向特別強

DSE 理科備考時，務必確保**物理、化學、生物均衡取高分**，並強烈建議選修數學 M2，以確保入讀香港頂尖理學院的競爭力；內地同學則應把握奧賽、科研經歷等加分位，提早部署獎學金策略。
