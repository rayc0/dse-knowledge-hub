# 香港八大 GPA 計算法與榮譽學位等級完整拆解（2026 年版）

> 摘要 — 香港八所資助大學沿襲英式榮譽學士制度（Honours Degree），畢業時按 GGPA（Graduation GPA）與「50% letter-graded credits」規則共同定出 First / 2:1 / 2:2 / Third 四個等級；GPA 滿分方面，HKU、HKUST、CityU 三校採 4.3 制，其餘五校採 4.0 制。無論是 DSE 考生、內地本科來港插班、或是已入學的本科生，理解這套體系都直接影響升碩、考公、IANG 留港的競爭力。

## 一、為何 GPA 與榮譽等級值得認真看待

港八大的學位證書與成績單上會**直接印出榮譽等級**，例如「Bachelor of Business Administration with First Class Honours」。換言之，榮譽等級本身就是學位的一部份，與內地「畢業證＋學位證」兩件制有根本分別。

這對本地 DSE 生、內地來港學生都有實際影響：

1. **升讀碩士**：英美頂尖項目（Oxbridge、IC、LSE）多以 **Second Class Upper（2:1）** 為最低門檻，部分熱門科系要求 **First**。
2. **IANG 與留港就業**：四大、投行、政府 AO 普遍以 2:1 作為初步篩選線，First 屬加分甚至入場券。
3. **回內地發展**：選調生、國企 HR 慣常把 GPA 換算成百分制；低於 3.0/4.0 的履歷，在激烈競爭崗位上較難突圍。
4. **獎學金申請**：港校內部獎學金（如 Entrance Scholarship、Dean’s Honours List）多以年度 GPA 或累計 GPA 為依據。

## 三、GPA 基本算式與 4.3 制示範

### 通識公式

```
GPA = Σ（課程學分 × 課程績點） ÷ Σ 課程學分
```

### 4.3 制常見評分對照（適用於 HKU、HKUST、CityU）

| 字母等級 | 參考分數區間 | 績點（Grade Point） |
|---------|------------|-------------------|
| A+ | 90–100 | 4.3 |
| A | 85–89 | 4.0 |
| A− | 80–84 | 3.7 |
| B+ | 75–79 | 3.3 |
| B | 70–74 | 3.0 |
| B− | 65–69 | 2.7 |
| C+ | 60–64 | 2.3 |
| C | 55–59 | 2.0 |
| C− | 50–54 | 1.7 |
| D+ | 45–49 | 1.3 |
| D | 40–44 | 1.0 |
| F | 0–39 | 0 |

### 計算示例（HKU BBA 學生，一學期 5 科）

| 科目 | 學分 | 成績 | 績點 | 學分 × 績點 |
|------|------|------|------|-------------|
| ACCT1101 | 6 | A | 4.0 | 24.0 |
| ECON1210 | 6 | A− | 3.7 | 22.2 |
| BUSI1002 | 6 | B+ | 3.3 | 19.8 |
| CAES1000 | 6 | B | 3.0 | 18.0 |
| CCCH9051 | 6 | A+ | 4.3 | 25.8 |
| **合計** | **30** |  |  | **109.8** |

**SGPA = 109.8 ÷ 30 ≈ 3.66**，約對應 **Upper Second（2:1）** 區間。

## 四、四級榮譽的 GPA 分檔

各校細節略有差異，但整體框架一致。以下為 2026 年度常見參考區間，4.0 制與 4.3 制均適用：

| 榮譽等級 | 英文 | 4.0 制 GGPA | 4.3 制 GGPA | 取得比例（參考） |
|---------|------|-------------|-------------|----------------|
| 一級榮譽 | First Class Honours | **≥ 3.60** | **≥ 3.60** | 約 10%–20% |
| 二級甲等榮譽 | Upper Second（2:1） | 3.00–3.59 | 3.00–3.59 | 約 35%–45% |
| 二級乙等榮譽 | Lower Second（2:2） | 2.40–2.99 | 2.40–2.99 | 約 20%–30% |
| 三級榮譽 | Third Class Honours | 1.70–2.39 | 1.70–2.39 | 約 5%–10% |
| 及格學位 | Pass Degree（無 Honours） | 1.00–1.69 | 1.00–1.69 | < 5% |

注意：

- **HKUST** 採雙軌：Major CGA 與 Overall CGA 須同時達標，**以較低一檔**為最終榮譽。
- **HKU** 除 GGPA 外設「**50% letter-graded rule**」：若 P/F 課程佔總學分超過一半，**只頒 Pass Degree**，不頒 Honours。
- 各校每年會微調分檔與比例，務必以當年 Registry 或 Academic Advising Office 公布為準。

## 五、HKU / CUHK / HKUST 三校深度差異

### HKU — Graduation GPA（GGPA）

- GGPA 涵蓋**所有已修課程**，**包含 F**（不及格仍以 0 計入分母）。
- 同時存在 SGPA（學期）、YGPA（年度）、CGPA（累計）、GGPA（畢業）四種；**只有 GGPA 用於榮譽判定**。
- 「50% letter-graded rule」：P/F 課程若佔總學分一半以上，畢業只獲 Pass Degree。

### CUHK — Cumulative GPA

- A+ 與 A 均記 4.0，**沒有 4.3 制**。
- 榮譽由 Cumulative GPA 決定；部分書院、雙學位項目設最低 2.0 畢業門檻。
- 設 **Discretionary rule**：成績處於分檔邊界時，學系可按專業課表現上下調整一檔。

### HKUST — MCGA + Overall CGA 雙軌

- **MCGA（Major CGA）**：只計算主修必修與選修。
- **Overall CGA**：計算所有學分課程。
- 榮譽以**較低一檔**為準；例：Overall 3.7、MCGA 3.4，最終頒 2:1 而非 First。
- 重修政策：**新成績取代舊成績**，但舊成績在成績單上會以「R」（Repeated）標示仍可見。

## 六、GPA 與內地百分制換算

並無官方單一公式，留服認證、HR 與獵頭圈普遍採用以下近似表：

| HK 4.0 GPA | 百分制換算 | 內地等級近似 |
|-----------|-----------|------------|
| 4.0 | 95–100 | 優秀 |
| 3.7 | 90–94 | 優秀 |
| 3.3 | 85–89 | 良好上 |
| 3.0 | 80–84 | 良好 |
| 2.7 | 75–79 | 中等上 |
| 2.3 | 70–74 | 中等 |
| 2.0 | 65–69 | 及格 |

對於 **4.3 制**，常見做法是線性映射（除以 4.3 再乘 4.0）。部分內地機構要求成績單後附 HKU 官方 *Grading System Explanation*；DSE 學生若日後計劃赴內地體制內求職，建議提前向相關學院申請學業證明信。

## 七、影響 GPA 的選課與學習策略

1. **別只看「好過」的水課**：HKUST 的 MCGA 只計主修課，主修分低會直接拉低榮譽等級。
2. **大一大二是基本盤**：多數港校頭兩年每學期約 30 學分，累計已佔畢業總學分近半；GPA 趨勢在前兩年已大致成形。
3. **慎用 P/F**：HKU 規定 P/F 課程不得超過總學分一半，否則失去 Honours。
4. **重修政策差異大**：
   - HKU：F 可重修，**新舊成績同時計入 GGPA**（取平均概念）。
   - HKUST：重修新成績**取代**舊成績。
   - CUHK：按科目政策，部分主修設重修上限（如 2 科）。
5. **交換學期**：大部分交換課程按 P/F 回轉、不計 GPA；若希望 letter grade 回轉，須於交換前向所屬學系確認。
6. **畢業論文／Capstone**：通常 6–12 學分，給分偏嚴謹；提早與導師對齊題目與進度，是避免拉低 GPA 的關鍵。

## 八、常見誤解

**誤解 1：把 4.3 制當 4.0 制比較**
→ HKU 的 3.7 與其他港校的 3.7 含義並不完全相同；4.3 制下頂檔被拉高，同等榮譽的難度相對較大。

**誤解 2：平均 80 分就能拿 First**
→ First 通常要求 GGPA ≥ 3.6，對應約 **A− 級別**整體水平，實際百分制多落在 85 分以上。

**誤解 3：忽略「50% letter-graded」規則**
→ 通識課用 P/F 是常見策略，但若超過一半學分屬 P/F，整個學位將只頒 Pass Degree。

**誤解 4：以為重修可「洗白」F**
→ HKU 採「同時並計」，重修只能部分拉高平均；HKUST 採「取代制」，差異極大。務必查清所屬學校條款。

**誤解 5：以為雙主修／雙學位各有一份 GPA**
→ 多數港校只頒一份 GGPA，覆蓋所有主修；Minor 不單獨頒榮譽。

**誤解 6：GPA Bell Curve 對自己一定有利或不利**
→ 相對評分（class-based curve）受班內強手比例影響。DSE 考生若來自名校重點組，入學初期在基礎課上競爭激烈；到了高階選修則可能反過來得益。

## 九、畢業後：碩士申請與就業的 GPA 參考

### 熱門升學目標（4.0 制門檻）

| 目標 | 典型 GPA 要求 |
|------|--------------|
| 牛津、劍橋、LSE、IC 頂級碩士 | 3.6+（First） |
| UCL、KCL、Edinburgh | 3.3+（2:1） |
| NUS、NTU 熱門碩士 | 3.3–3.5+（2:1） |
| 港大、中大、科大研究型碩士 | 3.3+（2:1，First 額外加分） |
| 美國 Top 30 碩士 | 3.5+ |
| 美國 Top 50 碩士 | 3.2+ |

### 香港就業方向

- **投行／諮詢／四大 Audit**：2:1 為入場券，First 為常見首輪篩選線。
- **政府 AO／EO**：不硬性要求 First，但招聘列明「good honours degree」。
- **科技公司**：GPA 為入場因素，技術能力與實習經驗同樣關鍵。
- **中資企業駐港**：更看重學校層級與實習脈絡，GPA 是加分項而非決定項。

## 十、常見問題（FAQ）

**Q1：掛科會否影響畢業？**
會。多數學校要求重修通過始可計入畢業學分；HKU 的 F 更會進入 GGPA 分母，直接拖累榮譽等級。

**Q2：港大 3.5/4.3 申請英碩時算 2:1 還是 First？**
多數英國院校列明：**GPA ≥ 3.6（不論 4.0 或 4.3 制）視為 First**；3.0–3.59 為 2:1。最終以目標院校 *country-specific requirements* 為準。

**Q3：重修後成績單會否顯示原來的 F？**
會。八大均採 transcript 全留痕制，原 F 標示為 R（Repeated）或 S（Superseded），新成績另行列示。

**Q4：GPA 與 CGA 是同一回事嗎？**
概念相同，名稱略異：HKUST 官方用 CGA（Cumulative Grade Average），HKU/CUHK/PolyU/CityU 多用 GPA / CGPA。對外場合（升學、僱主）一般通稱 GPA。

**Q5：雙學位畢業時會否頒兩個榮譽？**
多數情況下**只頒一份聯合榮譽**，依所有課程 GGPA 計算。少數與海外合辦的雙學位雙證項目，會分別頒授證書，榮譽獨立判定——以具體項目為準。

**Q6：大陸學生與 DSE 本地生在 GPA 計算上有分別嗎？**
沒有。入學渠道（DSE / 內地高考 / IB / A-Level）只影響 Year 0 或先修課安排；進入本科正課後，所有學生 GPA 計算與榮譽判定一視同仁。

**Q7：港校有沒有「大一保護期」？**
無統一機制。HKU 的部分 Common Core 可選 P/F（限額內），HKUST 若干基礎課允許在 drop deadline 前改 P/F；多數主修與核心課必須按字母評分。
