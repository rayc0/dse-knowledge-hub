# 香港大學傳播與新聞課程全攻略——DSE考生升學懶人包

傳播與新聞（Communications and Journalism）向來是香港高等教育的王牌學科之一，憑藉雙語環境、國際視野及亞洲媒體樞紐的地理優勢，孕育出無數紮根香港、內地以至全球媒體行業的專才。對於透過DSE報考JUPAS的同學而言，傳播學既是熱門之選，亦是競爭激烈之路。本文從學科內容、院校特色、入學門檻到職場前景作系統梳理，協助你規劃升學路向。

## 一、三大學府課程速覽

### 1.1 香港浸會大學（HKBU）——傳理學院

浸大傳理學院被譽為亞太區新聞傳播教育的重鎮，學系分拆精細：

| 學系 | 核心範疇 |
|---|---|
| 新聞系（Journalism） | 採訪寫作、調查報道、融合媒體新聞 |
| 電影學院（Cinema） | 影視製作、紀錄片、劇本創作 |
| 廣播學系（Radio & Television） | 廣播新聞、主持技巧 |
| 傳播研究（Communication Studies） | 媒體理論、受眾分析、健康傳播 |
| 數碼媒體與電視（Digital Media） | 數碼內容創作、跨平台敘事 |
| 綜合傳播管理（COMS） | 公關策略、廣告企劃、危機傳訊 |

**學院亮點：**
- 與無綫電視（TVB）、香港電台（RTHK）等本地主流媒體設有恆常實習機制
- 設有「亞洲傳播研究中心」，提供本科生研究項目資助
- 學科排名長期位列亞洲前列

### 1.2 香港中文大學（CUHK）——新聞與傳播學院（SJIC）

| 課程主修 | 教學特色 |
|---|---|
| 新聞與傳播（BA） | 採編實務與傳播理論並重 |
| 廣告學 | 品牌策略、創意管理 |
| 公共關係 | 機構傳訊、危機處理 |
| 全球傳播（Global Communications） | 跨文化研究、全英教授 |

**學院亮點：**
- 學術研究底子深厚，兩岸三地傳播生態研究獨具優勢
- 與央視、《人民日報》等內地主流媒體建有合作渠道
- 「全球傳播」課程為有志投身國際機構的學生而設

### 1.3 香港大學（HKU）——新聞及媒體研究中心（JMSC）

| 課程 | 修讀模式 |
|---|---|
| 新聞學（主修） | 全英語新聞專業訓練 |
| 數碼新聞 | 數據新聞、互動多媒體敘事 |

**學院亮點：**
- 英語教學為主，貼近國際新聞運作模式
- 與路透社、BBC、彭博社等跨國媒體有實習合作
- 國際化程度冠絕同類學系，適合立志成為國際新聞工作者

## 二、必修學科單元拆解

### 2.1 新聞寫作與編採

| 課題 | 學習重點 |
|---|---|
| 新聞價值判斷 | 5W1H框架、消息來源鑑別 |
| 寫作結構 | 倒金字塔寫法、標題與導言、特寫技巧 |
| 調查報道 | 資料核查、數據分析、資訊公開申請 |
| 多媒體新聞 | 短片新聞、Podcast製作、新聞攝影 |
| 數據新聞 | Tableau、Datawrapper等視覺化工具 |

### 2.2 媒體法與新聞倫理

| 課題 | 學習重點 |
|---|---|
| 香港傳媒法 | 誹謗法、消息來源保密、版權法 |
| 倫理框架 | 準確性、公平報道、私隱與公眾利益 |
| 監管機制 | 通訊事務管理局（OFCA）的職能 |
| 社交媒體法律 | 平台審理、網絡發佈的法律責任 |

### 2.3 數碼新聞與新媒體

| 課題 | 學習重點 |
|---|---|
| 內容策略 | SEO基礎、受眾分析、發佈渠道管理 |
| 社交平台營運 | Instagram、微信、TikTok平台邏輯 |
| 數據工具應用 | Python入門、數據處理基礎 |
| 互動新聞 | 使用者體驗、資訊圖表設計 |

### 2.4 公關與廣告

| 課題 | 學習重點 |
|---|---|
| 機構傳訊 | 媒體關係、危機管理 |
| 廣告策略 | 受眾定位、品牌定位、創意構思 |
| 整合營銷傳播（IMC） | 跨平台協同效應 |
| 公益傳播 | 非政府組織倡議、社會運動設計 |

## 三、雙語訓練——港式傳播教育的核心優勢

香港傳播教育最難被複製的特點，正是中英雙語並行教學：

| 語言技能 | 訓練方式 |
|---|---|
| 英文新聞寫作 | 大量實作，達至國際通訊社稿水平 |
| 粵語廣播 | 標準粵語播報訓練 |
| 普通話新聞 | 內地合作項目，銜接大灣區職場 |
| 中英翻譯 | 新聞稿雙語轉換練習 |

> **過來人貼士：** 粵語是香港媒體日常運作的主要語言，新來港的同學宜在學期間積極操練，至少達至日常對答及聆聽水平。

## 五、DSE選科策略

| 升學方向 | 強烈建議選修 | 加分選修 |
|---|---|---|
| 新聞系 | 英文（5級以上）、中文 | 歷史、公民與社會發展／經濟 |
| 廣告／公關 | 英文、經濟或企業、會計與財務概論 | 視覺藝術、數學 |
| 電影／廣播 | 英文、中文、視覺藝術（如有） | 音樂、歷史 |
| 傳播研究 | 英文、人文社科 | 統計學（數學M1／M2） |

> **語文門檻提示：** 各大新聞傳播課程對英文水平要求偏高，建議至少達到 **Level 4**，具競爭力的考生宜達 **Level 5**。

## 六、入學門檻參考

| 院校課程 | 最佳5科總分約值 | 英文要求 | 附加要求 |
|---|---|---|---|
| HKBU 新聞系 | 24—28（滿分42） | Level 4 | 英文寫作測試／面試 |
| HKBU 電影／傳播 | 22—26（滿分42） | Level 3+ | 作品集／面試 |
| CUHK 新聞與傳播 | 25—29（滿分42） | Level 4 | 面試 |
| HKU 新聞系 | 26—30（滿分42） | Level 4—5 | 寫作能力測試 |

*數據為歷年收生中位參考，最終以該年度JUPAS公布為準。*

## 七、面試與作品集準備清單

傳播學系重視申請人的**實戰經驗**及**個人視野**，以下準備方向有助突圍：

| 準備項目 | 具體做法 |
|---|---|
| 校內媒體經驗 | 校刊編輯、校園社交平台管理 |
| 公開寫作紀錄 | 個人專欄、博客、社交平台長文創作 |
| 視覺作品集 | 短片、攝影集、Podcast節目 |
| 新聞實習 | 任何形式的採訪、編輯實習皆可 |
| 活動策劃 | 校內活動統籌、辯論比賽、模擬聯合國 |

## 八、香港 vs. 內地頂尖傳播院校

| 比較維度 | 香港（HKBU／CUHK／HKU） | 中國傳媒大學 | 復旦大學新聞學院 |
|---|---|---|---|
| 亞洲排名 | 多項學科位列前20 | 內地頂尖 | 內地頂尖 |
| 英語新聞訓練 | 比重高、要求嚴 | 有但比重較低 | 有但比重較低 |
| 國際實習機會 | 豐富 | 以內地機構為主 | 以內地機構為主 |
| 內地媒體網絡 | 透過兩地合作拓展 | 直接對接 | 對接較強 |
| 學術討論空間 | 相對開放 | 受政策框架規範 | 受政策框架規範 |
| 畢業生流向 | 全球，獲歐美媒體認可 | 主要留內地 | 主要留內地，海外為輔 |

## 九、總結

香港的新聞傳播教育為有志投身媒體行業的DSE考生提供獨一無二的跳板。**浸大傳理學院**與**中大新聞與傳播學院**為本地雙主流選擇；**港大JMSC**則是英語國際媒體路向的首選。在學期間，應把握三大關鍵：強化英語新聞寫作、熟習香港媒體生態、將自身內地背景轉化為差異化競爭力。隨着大灣區媒體融合加速，兼具雙語能力與跨文化視野的畢業生，將在未來職場擁有更廣闊的選擇空間。
