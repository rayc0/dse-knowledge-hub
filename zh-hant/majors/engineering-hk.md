# 香港大學工程學科完全指南——DSE 考生視角

工程學（Engineering）一直是香港最受歡迎的學科之一，不論在環球排名、產業聯繫，還是畢業出路方面，都具有相當吸引力。對以 DSE 報考 JUPAS 的同學而言，工程學既是熱門之選，亦競爭激烈。本文將由 DSE 選科、計分方法，到各校課程特點、實習機會及專業資格，作一次系統性整理。

## 一、八大院校工程學系總覽

香港共有四所大學設有規模較大的工程學院，其中以香港科技大學（HKUST）、香港大學（HKU）、香港理工大學（PolyU）與香港城市大學（CityU）最為主流。以下逐一介紹。

### 1.1 香港科技大學（HKUST）——工學院

科大工學院被視為亞洲頂尖的工程教育樞紐，學系劃分亦較細緻：

| 學系 | 主要專業範疇 |
|---|---|
| 計算機科學及工程學（CSE） | 人工智能、軟件工程、網絡安全、數據科學 |
| 電子及計算機工程學（ECE） | 晶片設計、嵌入式系統、無線通信 |
| 化學及生物工程學（CBE） | 新能源材料、生物醫學工程、環境工程 |
| 土木及環境工程學（CIVL） | 智慧城市基建、綠色建築 |
| 工業工程及決策分析（IEDA） | 運籌學、工程管理、大數據分析 |
| 機械及航空工程學（MAE） | 機器人、無人機、航空航天 |

科大在 QS 工程學科排名中長期位列亞洲五名以內，並透過 HKUST（GZ）進一步加強大灣區影響力。

### 1.2 香港大學（HKU）——工程學院

港大工程學院歷史悠久，與本港基建及政府工程項目關係密切：

| 學系 | 課程特色 |
|---|---|
| 計算機科學（CS） | 深度學習、區塊鏈、大數據 |
| 電機及電子工程學（EEE） | 智能電網、光電子學、通訊系統 |
| 土木工程學（Civil） | 參與本港大型基建顧問項目 |
| 機械工程學（MechE） | 精密製造、能源工程 |
| 工業及製造系統工程學（IMSE） | 供應鏈管理、工業 4.0 |

港大提供雙主修（Double Major）及副修（Minor）組合，同學可靈活跨工程與商科、計算機科學等領域。

### 1.3 香港理工大學（PolyU）——工程學院

理大前身為工業學院，工程教育一向以應用導向見稱：

| 學系 | 課程特色 |
|---|---|
| 土木及環境工程學（CEE） | 國際排名領先，參與本港多項大型基建 |
| 電子及資訊工程學（EIE） | 物聯網、嵌入式系統、機器人 |
| 機械工程學（ME） | 與內地製造業聯繫緊密 |
| 工業及系統工程學（ISE） | 智能製造、品質管理 |
| 生物醫學工程學（BME） | 醫療儀器研發與臨床合作 |

理大的土木工程於 QS 學科排名中位列全球前 25 名，是該校最具代表性的工程學科。

### 1.4 香港城市大學（CityU）——工學院

城大工學院以跨學科研究聞名，特別在納米科技與生物醫學領域：

| 學系 | 課程特色 |
|---|---|
| 計算機科學（CS） | AI、數據科學、雲端運算 |
| 電機工程學（EE） | 可再生能源、電力系統 |
| 機械工程學（ME） | 3D 打印、航空工程 |
| 生物醫學工程學（BME） | 與城大醫學院協作 |
| 土木工程學（CE） | 城市工程、災害防控 |

城大與深圳科技企業合作頻繁，對於希望投身大灣區創科產業的同學具吸引力。

## 四、DSE 選科與入學要求

### 4.1 通用入學門檻

| 科目 | 一般要求 |
|---|---|
| 數學（必修） | **Level 4 或以上**，幾乎所有工程課程必看 |
| 數學延伸（M1/M2） | **強烈建議**，部分課程列為必要條件 |
| 物理 | **Level 3—4 或以上**，大部分工程方向的指定選修 |
| 化學 | 化學工程、材料工程、生物醫學工程指定要求 |
| 英文 | **Level 3 或以上**，工程教學語言以英文為主 |

### 4.2 各工程方向選科建議

| 工程方向 | 建議 DSE 組合 | 備註 |
|---|---|---|
| 計算機／軟件工程 | 數學＋M2＋物理（或 ICT） | M2 提供微積分基礎 |
| 電機／電子工程 | 數學＋M2＋物理 | 電磁學與電路學的基礎 |
| 機械工程 | 數學＋M2＋物理 | 流體力學與熱力學所需 |
| 土木工程 | 數學＋物理（+地理有助） | 結構分析需數學基礎 |
| 化學工程 | 數學＋化學＋物理 | 化學為必要 |
| 生物醫學工程 | 數學＋生物＋化學（+物理） | 生物背景有利 |

## 六、四年制與五年制課程

香港工程學位主要分為四年制及五年制兩種，差異如下：

| 比較項目 | 四年制學士 | 五年制（含實習／交流） |
|---|---|---|
| 常見院校 | HKU、HKUST、CityU | PolyU 部分課程 |
| 優點 | 較快完成學位，節省學費 | 設有系統性實習年，競爭力更強 |
| 缺點 | 實習需自行安排 | 額外一年學費與生活費 |
| 專業認可 | 同樣可申請 HKIE Graduate Member | 實習年有助更快取得企業會員資格 |

### 6.1 專業資格——香港工程師學會（HKIE）

- 畢業後可申請成為 **Graduate Member（研究生會員）**
- 累積約四年相關工程經驗，並通過評核後，可晉升為 **Corporate Member（企業會員）**
- Corporate Member 相當於註冊工程師專業資格，是工程師在港執業的重要門檻

## 七、本科研究機會

香港的工程學院普遍重視本科生科研參與，以下為各校主要計劃：

| 院校 | 本科研究計劃 |
|---|---|
| HKUST | Undergraduate Research Opportunities Program（UROP）——加入教授研究室可獲學分 |

## 八、與內地頂尖工科院校比較

不少同學會將香港院校與清華、中科大等內地名校作比較，以下從 DSE 視角整理：

| 比較項目 | 香港（HKUST／HKU） | 清華大學 | 中國科學技術大學 |
|---|---|---|---|
| QS 工程全球排名 | 約 40—60 | 約 20—30 | 約 50—80 |
| 國際化程度 | 極高（全英文教學） | 中等（近年提升） | 中等 |
| 海外升學銜接 | 非常便利 | 高 | 高 |
| 內地產業聯繫 | 透過大灣區合作 | 直接 | 相對間接 |
| 每年學費 | 約 HKD 14 萬 | 約 RMB 5,000（補貼價） | 約 RMB 5,000 |
| 住宿費 | 額外 HKD 3—5 萬 | 低 | 低 |

> 香港院校學費較高，但對國際升學及跨境就業有明顯優勢。

## 九、DSE 備考與選校策略

1. **數學 M2 為關鍵**：幾乎所有頂尖工程課程都涉及微積分與線性代數，M2 表現越好，越具競爭力
2. **物理必須穩固**：DSE 物理 Level 4 以上是基本門檻，力學與電磁學佔分較重，宜及早打底
3. **英文能力不可忽視**：工程教材與考試以英文為主，DSE 英文 Level 4 以上較為穩妥
4. **ICT 為輔助選修**：對計算機科學或軟件工程方向，ICT（資訊及通訊科技）有加分作用
5. **善用 UROP 與 Summer Fellowship**：入讀後及早參與研究項目，有助日後申請研究生或加入創科企業
6. **留意聯招及非聯招途徑**：本地 DSE 考生以 JUPAS 為主；國際課程或非本地身份考生需透過 Non-JUPAS 申請

## 十、總結

香港工程學科為 DSE 考生提供了一個結合國際排名、英文教學與大灣區產業資源的獨特升學路徑。科大適合追求科研與國際聲譽的同學；理大在土木及應用工程方面根基深厚；港大與城大則在跨學科組合上較為靈活。DSE 同學宜按自身選科組合、語文能力及職業志向作綜合考慮，提前規劃 M2 與物理的應試策略，並透過 UROP、實習計劃等裝備自己，為日後投身工程專業奠定基礎。
