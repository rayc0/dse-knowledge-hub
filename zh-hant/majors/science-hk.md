# 香港大學理學科完全指南——內地生視角

理學（Science）一直是香港頂尖大學科研實力最為突出的學科群之一。無論是物理、化學抑或生命科學，香港科技大學、香港大學及香港中文大學的理學院均於國際頂級期刊發表大量論文，為有志投身科研或學術事業的內地學生提供了極具吸引力的舞台。本文將從課程結構、科研環境、升學出路、選科策略，以至與內地頂尖院校之比較，逐一向有志入讀的同學拆解。

## 一、三所大學理學課程一覽

### 1.1 香港科技大學（HKUST）—— 理學院（School of Science）

| 課程 | 重點方向 |
|---|---|
| 物理學（Physics） | 凝聚態物理、量子物理、天體物理 |
| 化學（Chemistry） | 藥物化學、納米材料、綠色化學 |
| 生物化學及細胞生物學（Biochemistry & Cell Biology） | 細胞生物學、分子遺傳學、神經科學 |
| 數學（Mathematics） | 純數學、應用數學、數據科學 |
| 海洋科學（Ocean Science） | 海洋生態、氣候變化、海洋地質 |

**科研亮點：**
- HKUST 物理系與國際物理學前沿接軌緊密，多位教授為美國物理學會會士（APS Fellows），於凝聚態物理及量子材料領域具亞洲領先地位
- 與中科院多個研究所設有聯合實驗室或合作項目
- 本科生可透過 UROP（Undergraduate Research Opportunities Program）參與前沿課題

### 1.2 香港大學（HKU）—— 理學院（Faculty of Science）

| 課程 | 重點方向 |
|---|---|
| 生物化學（Biochemistry） | 蛋白質結構、基因組學、癌症生物學 |
| 生物學（Biology） | 生態學、演化生物學、海洋生物 |
| 化學（Chemistry） | 有機合成、計算化學、藥物開發 |
| 地球科學（Earth Sciences） | 地質學、氣候科學、自然災害 |
| 數學（Mathematics） | 偏微分方程、數論、概率論 |
| 物理學（Physics） | 理論物理、天體物理、量子信息 |
| 統計學（Statistics） | 生物統計、金融統計、機器學習 |
| 環境科學（Environmental Science） | 大氣科學、水文學、污染控制 |

**特色：**
- HKU 理學院與李嘉誠醫學院協作緊密，生命科學及生物化學方向科研實力雄厚
- 與香港天文台、衞生署、土木工程拓展署等政府機構合作密切

### 1.3 香港中文大學（CUHK）—— 理學院（Faculty of Science）

| 課程 | 特色 |
|---|---|
| 生物化學（Biochemistry） | 結合中醫藥研究的獨特傳統 |
| 化學（Chemistry） | 材料化學、界面科學 |
| 地球系統科學（Earth System Science） | 氣候變化、遙感技術 |
| 數學（Mathematics） | 應用數學（金融數學）見稱 |
| 物理（Physics） | 表面科學、磁性材料 |
| 生命科學（Life Sciences） | 跨學科整合培訓 |
| 統計及數據科學（Statistics） | 生物統計、經濟統計 |

**特色：**
- 書院制學習社區為理科學生提供豐富跨院系活動
- 中醫藥與現代生命科學交叉研究享國際聲譽

## 二、學科細分與出路

### 2.1 物理學（Physics）

| 分支 | 研究內容 | 升學／就業出路 |
|---|---|---|
| 凝聚態物理 | 超導體、量子材料、納米結構 | 學術研究、半導體行業 |
| 量子信息 | 量子計算、量子密碼 | 科技企業、國家實驗室 |
| 天體物理 | 宇宙學、黑洞、引力波 | 以學術研究為主 |
| 計算物理 | 數值模擬、高性能計算 | 量化金融、氣候模型 |

### 2.2 化學（Chemistry）

| 分支 | 研究內容 | 就業出路 |
|---|---|---|
| 有機化學 | 新藥合成、天然產物 | 藥企研發、醫療器械 |
| 無機／材料化學 | 功能材料、催化劑 | 材料公司、新能源 |
| 分析化學 | 儀器分析、食品安全檢測 | 食品／環境檢測機構 |
| 計算化學 | 分子模擬、藥物設計 | AI 藥物發現公司 |

### 2.3 生命科學（Biology / Biochemistry）

| 分支 | 研究內容 | 就業出路 |
|---|---|---|
| 分子生物學 | DNA 複製、基因表達、基因編輯 | 生物科技公司、基因檢測 |
| 細胞生物學 | 幹細胞、癌症機制 | 製藥公司、醫院研究部 |
| 生態學 | 生物多樣性、環境變化 | 環保機構、政府部門 |
| 微生物學 | 病毒學、抗生素研究 | 公共衞生、生物安全 |

### 2.4 環境科學（Environmental Science）

環境科學課程結合大量本地研究項目：
- 珠三角大氣污染監測（與粵港科研合作密切）
- 南中國海海洋生態研究
- 城市熱島效應與氣候政策分析
- 山泥傾瀉及自然災害風險評估

- 多位 HKUST 物理學教授為 APS Fellow，並與海外頂尖實驗室維持長期合作
- 與 MIT、加州大學柏克萊分校、史丹福大學等設有聯合研究項目
- 於量子材料、拓撲物理等前沿領域處於亞洲領先行列

## 四、通往博士與學術研究的階梯

### 4.1 本科後典型進階路徑

```
BSc（4 年）
    ↓
MPhil / MSc（1—2 年） ← 香港或海外
    ↓
PhD（3—5 年）         ← 香港 / 英美頂尖大學
    ↓
博士後（2—3 年）      ← 國際流動
    ↓
學術職位（由助理教授起步）
```

### 4.2 香港博士研究的優勢

- 香港博士生可透過研究資助局（RGC）轄下香港博士獎學金計劃（HKPFS），每月獲約 **HKD 28,100** 津貼，並另設會議及研究差旅資助
- 香港博士學位獲英美頂尖大學高度認可，便利日後國際流動
- 與內地科研合作密切，可於兩地實驗室之間靈活交流

### 4.3 直升海外頂尖博士

- 完成香港頂尖大學 BSc 後，歷年均有畢業生獲 MIT、哈佛、史丹福、加州理工等錄取攻讀博士
- HKUST 物理及化學本科生成功申請海外頂尖博士的比例尤其突出

## 五、DSE 理科選科攻略

### 5.1 各目標專業的最佳組合

| 目標專業 | 最佳 DSE 組合 | 原因 |
|---|---|---|
| 物理學 | 物理 + 數學 M2 + 化學 | 物理為核心，M2 提供微積分基礎 |
| 化學 | 化學 + 物理 + 數學 M2 | 化學為核心，物理與數學互補 |
| 生物化學 | 化學 + 生物 + 物理 | 三科並重，有機化學基礎不可或缺 |
| 生物學 | 生物 + 化學 + 物理／地理 | 生物為核心，輔以化學知識 |
| 環境科學 | 生物 + 地理 + 化學 | 地理提供地球系統視野 |
| 數學／統計 | 數學 M1／M2 + 物理（甚或經濟） | 數學基礎最為關鍵 |

### 5.2 聯合科學（Combined Science）注意

- DSE 提供聯合科學選項：物理 + 化學 或 生物 + 化學
- 聯合科學佔 1 個選修科位置，惟不少收生標準對其與「獨立科目」之換算方法不一
- **建議**：有志報考 HKUST／HKU 理學院者，應盡量分開選修獨立物理與獨立化學，以增強競爭力

## 六、內地生獎學金一覽

### 6.1 各大學本科獎學金

| 獎學金 | 院校 | 內容 |
|---|---|---|
| 內地本科生獎學金 | HKUST | 全額學費 + 生活津貼 |
| HKU 卓越獎學金計劃 | HKU | 全額或部分資助 |
| CUHK 全額獎學金 | CUHK | 全額學費 + 生活補貼 |
| 香港博士獎學金計劃（HKPFS） | 全港資助 | 每月 HKD 28,100 + 會議津貼 |

### 6.2 內地理科生的申請優勢

- 內地生在數學及自然科學 DSE 成績普遍較高，有助提升獎學金評審分數
- 曾於全國中學生物理、化學、生物奧林匹克競賽獲獎者，在入學及獎學金評審中具明顯優勢
- 部分院校設有「學系推薦」機制，獲教授撰寫推薦信可大幅加分

## 七、與內地頂尖理科院校比較

| 維度 | 香港（HKUST／HKU／CUHK） | 清華大學理學院 | 中國科學技術大學（USTC） |
|---|---|---|---|
| QS 自然科學排名 | 全球約 70–120 名 | 全球約 20–40 名 | 全球約 40–80 名 |
| 國際化程度 | 極高（全英教學） | 中等（部分英文授課） | 較低（主要中文授課） |
| 科研經費 | 中等（港府 RGC 資助為主） | 高（國家重點資助） | 高（國家重點資助） |
| 國際學術網絡 | 與英美頂尖大學聯繫緊密 | 國際合作日增 | 以內地體系為主 |
| 海外升博認受性 | 極高 | 高 | 高 |
| 本科科研機會 | 豐富（UROP 等） | 豐富 | 極豐富（科研為本） |
| 內地生學費 | 約 HKD 14 萬／年 | 約 RMB 5,000／年 | 約 RMB 5,000／年 |
| 生活成本 | 高（香港物價） | 中等 | 較低 |

**香港理科的核心吸引力：**

1. 全英學術訓練，對日後赴海外深造極為有利
2. 教授團隊多有海外頂尖大學背景，接觸國際學術前沿機會多
3. 大灣區科研走廊：與深圳創科產業近在咫尺，實習與就業機會兼具

## 八、AI 時代下的理科新出路

| 趨勢 | 對理科生的影響 |
|---|---|
| AI + 生命科學 | 生物信息學、AI 藥物發現渴求生化 + 計算機雙背景人才 |
| 量子計算商業化 | 物理學背景人才於量子計算企業極為稀缺 |
| 可再生能源 | 化學／材料科系畢業生於電池、光伏領域前景廣闊 |
| 氣候科學 | 環境科學 + 大數據 = 氣候模型研究新需求 |

香港頂尖大學近年積極推出**跨學科雙主修**（如物理 + 計算機、生物化學 + 數據科學），內地理科生可善用此靈活課程設計，提升跨界競爭力。

## 十、總結

香港頂尖大學理學院為內地學生提供全球認可的國際化科學教育平台，英文訓練與豐富的科研機會，使畢業生於海外博士申請中佔有明顯優勢。HKUST 於物理與化學兩大領域科研實力最為突出；HKU 之生命科學與醫學院協同效應顯著；CUHK 則以跨學科理學教育及應用數學見長。內地學生備考 DSE 時，建議確保**物理、化學、生物三科均衡取得高分**，並強烈建議加選數學 M2，以增強入讀頂尖理學院的競爭力。
