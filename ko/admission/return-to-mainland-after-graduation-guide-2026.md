## 1. 왜 류푸 인증이 반드시 필요한가

홍콩 8대 본과를 졸업한 본토 출신 학생이 받는 것은 **홍콩 대학의 학사 학위증(Bachelor's Degree Certificate)**입니다. 홍콩 현지 및 해외에서는 추가 절차 없이 그대로 통하지만, 본토로 돌아가면 거의 모든 "체제 내(体制内)" 시나리오에서 **교육부 산하 중국유학서비스센터가 발행한 《홍콩·마카오 특별행정구 학력학위 인증서》** 제출을 요구합니다.

류푸 인증이 필요한 대표 상황을 정리하면 다음과 같습니다.

| 상황 | 인증 필요 여부 | 비고 |
|---|---|---|
| 본토 석사 입시(통일시험/추천면제/港澳台 대학원모집) | ✅ 필수 | 지원 시 인증서 번호 제출, 또는 합격 후 보완 |
| 국가 공무원시험(국考·성급·선택조치생) | ✅ 필수 | 자격 심사 단계부터 요구 |
| 사업단위 채용 | ✅ 필수 | 대부분 직무 |
| 중앙·국유기업 캠퍼스·사회 채용 | ✅ 대부분 직무 | 국자위 직속 기업은 특히 엄격 |
| 대도시 落户(베이징·상하이·광저우·선전 인재 도입) | ✅ 필수 | 상하이 落户 정책에 8대가 "세계 50/100대" 명단 포함 |
| 자격증(교사자격, 법률자격, CPA, 의사) | ✅ 필수 | 일부는 전置 학력 인증 추가 필요 |
| 민영·외국기업 취업 | ❌ 필수는 아님 | 단, 인사담당자가 사실 확인하는 경우가 많음 |

**결론:** 향후 5년 내에 본토로 돌아갈 가능성이 단 1%라도 있다면, 졸업 즉시 류푸 인증을 신청해 두는 것이 가장 안전한 보험입니다.

## 2. 법적 근거와 8대의 위상

교육부와 홍콩 특별행정구 정부教育局는 2004년 《내지와 홍콩 간 고등교육 학위증 상호인정에 관한 각서》를 체결했고, 2023년에 보충 개정했습니다. 주요 골자는 다음과 같습니다.

- 홍콩 8대(HKU/CUHK/HKUST/PolyU/CityU/HKBU/LingU/EdUHK)의 학사·석사·박사 학위를 본토에서도 인정.
- 인증 주관기관은 교육부 산하 **중국유학서비스센터(CSCSE)**.
- 8대가 아닌 홍콩 대학(예: 마카오대학會大學 OUHK, 홍콩주해대학 SYU, 행생대학 HSUHK 등)도 대다수 인증 범위 안에 있으나, **학교별로 반드시 확인이 필요**합니다.

**본토 체제 내 위상 체감 순위**

1. HKU(港大), CUHK(中大), HKUST(科大) → 칭화·베이징대·푸단·교통대급으로 인식
2. PolyU(理大), CityU(城大) → C9을 제외한 985 수준
3. HKBU(浸大), LingU(岭大), EdUHK(教大) → 일반 211/강력한 쌍일류 학과급

> 참고: 상하이 落户 "세계 50대" 명단(2024년판)에는 HKU/CUHK/HKUST가 포함되어 있고, "100대"에는 PolyU/CityU가 추가됩니다. HKBU/LingU/EdUHK는 별도 점수제를 통해 落户해야 합니다.

## 3. 류푸 인증 신청 전 과정 (2026년판)

### 3.1 신청 시기

- **가장 빠른 시점:** 졸업증서 + 성적표가 정식으로 발급되는 날(보통 졸업식 2~4주 전)
- **권장 시점:** 학위증 전자본을 받는 즉시 온라인으로 제출. 종이본을 기다릴 필요 없음
- **처리 기간:** 영업일 기준 10일. 가속(加急) 서비스는 2018년에 폐지됨
- **비용:** 360위안(인증서 배송 포함)

### 3.2 제출 서류

1. **학위증 컬러 스캔본** (Degree Certificate)
2. **전체 성적표 스캔본** (Official Transcript, 모든 학기 + GPA/Honours Classification 포함)
3. **신분증** (본토 신분증 정면·후면 +港澳通行證 또는 SAR 여권 인용 페이지)
4. **홍콩 유학 비자(Student Visa) 모든 签注 페이지 스캔본** — 홍콩 실제 거주 일수 검증용 핵심 자료
5. **학信网(學信網) 학적 조회 결과** — 홍콩 대학 입학 전 본토 고교/대학 학력 확인용
6. **위임각서** — 시스템에서 자동 생성되며 전자 서명即可

⚠️ 2024년부터 CSCSE가 "홍콩 실제 거주 기간" 심사를 눈에 띄게 강화했습니다. 교환·온라인 수업·원격 수업 등의 상황에는 출입국 기록을 추가 제출해야 합니다.

### 3.3 온라인 절차

1. 공식 사이트 접속: `https://zwfw.cscse.edu.cn` (해외 학력학위 인증 시스템)
2. 계정 가입(최초 사용 시 본인인증 + 안면인식 필요)
3. "홍콩·마카오 특별행정구" → "학사 학위" 선택
4. 자료 업로드 (PDF/JPG, 단일 파일 5MB 미만)
5. 온라인 결제 RMB 360
6. 심사 대기(시스템에서 진행 상황 확인 가능)
7. 통과 후 **전자 인증서(PDF)**가 계정으로 즉시 발송됨. 종이본은 2019년 이후 전면 폐지됨

### 3.4 자주 거절되는 사유와 보완 방법

| 거절 사유 | 비율 | 해결 방법 |
|---|---|---|
| 성적표 불완전(특정 학기 누락) | 약 35% | 학교에 가서 전체 transcript 재발급 |
| 비자 签注 페이지 누락 | 약 25% | Student Visa 모든 签注 + 출입국 기록 보완 |
| 학위증 번역본 미비 | 약 10% | 8대는 대부분 중영 병기 증서 발행; 영어 단독본일 경우 중국어 번역 추가 |
| 홍콩 체류 기간 부족 | 약 15% | 출입국 기록으로 소명; 2020~2022년 팬데믹 기간 원격수업은 과도기 정책 적용 |
| 학信网 학적 정보 불일치 | 약 10% | 학信网에서 본토 고교/전置 학력 정보 정정 |

## 4. 본토 진출 세 가지 주요 경로

### 4.1 考研(석사입학시험)

8대 본과생이 본토에서 석사를 따는 길은 크게 셋입니다.

#### A. 통일시험(매년 12월)

- **응시 자격:** 류푸 인증서 번호만 있으면 지원 가능. 졸업 당해 12월에는 인증서 없이 먼저 접수하고, 이듬해 9월 입학 전 보완 가능
- **준비 팁:** 정치, 영어Ⅰ/Ⅱ, 수학 등 공통과목을 별도로 보충해야 합니다. 홍콩 학부 과정에 해당 과목이 없기 때문에 독학 또는 학원이 필수
- **시험장:** 홍콩 시험장(HKU·CUHK 등에 설치된 본토 연구조교 주관) 또는 본토 시험장에서 선택 가능

#### B.港澳台聯招(연합모집)

- 홍콩·마카오·대만 거주자 전용으로 경쟁이 통시험보다 낮음
- 본토 출신 학생은港澳 영주권이 없으면 지원 불가

#### C. 해외 석사 직행

- 홍콩 본교 석사, 싱가포르·영국·미국 석사를 바로 지원하는 경로가 가장 흔합니다
- 8대 학부생은 본교 및 홍콩 타 대학 석사 지원 시 **동문 가산점**이 암묵적으로 적용되는 경우가 많음

### 4.2 考公(공무원시험)

**핵심:** 2023년부터 여러 성(省)의 선택조치생(选调生) 정책이 **8대 학부를 "쌍일류(双一流)" 동등 자격으로 명시 인정**하기 시작했습니다. 다만 성별로 차이가 큽니다.

| 성(省) | 8대 학부 인정 여부 | 비고 |
|---|---|---|
| 광둥 | ✅ 선택조치생 지원 가능 | HKU/CUHK/HKUST/PolyU/CityU 명시 포함 |
| 상하이 | ✅ 방향성 선택조치 | HKU/CUHK/HKUST에 한함 |
| 장쑤 | ✅ 선택조치생 지원 가능 | QS 100위 전부 포함 |
| 저장 | ✅ 선택조치생 지원 가능 | 8대 전원 포함 |
| 베이징 | ⚠️ 일부 직무만 | 직무별 공고 확인 필요 |
| 국考(국가직) | ✅ 대부분 직무 | 류푸 인증서 필수 |

**일정:** 졸업 전년도 9월 국考 공고 체크 → 10월 접수 → 11월 말 필기. **류푸 인증은 3개월 전에 끝내두는 것이 안전**합니다.

### 4.3 취업(중앙·국유기업·외국·민영 기업)

**캠퍼스 채용 채널**

- 8대 학부생은 **홍콩 현지 채용**(외자, 4대 회계법인, 투자은행, 빅테크)과 **본토 채용**(가을 채용 9~11월·봄 채용 3~5월)을 **동시에** 응시 가능
- 본토 캠퍼스 채용은 대부분 류푸 인증서를 요구하거나, "졸업 후 6개월 내 보완"을 조건으로 허용

**落户 정책(2025년 업데이트)**

- 상하이: HKU/CUHK/HKUST 졸업생 즉시落户; PolyU/CityU는 "세계 100대" 명단 내 자격 충족 시落户 가능
- 베이징: 应届生(응届생) 도입 채널을 통해 8대 전원 지원 가능
- 선전: 학사 학위 + 만 35세 이하이면 核准制入户 신청 가능
- 광저우: 점수제(积分)入户. 8대 학부는 가산점 부여

## 5. 놓치기 쉬운 5가지 디테일

1. **Honours Classification ≠ GPA**: 홍콩 성적표의 "First Class Honours / Upper Second / Lower Second / Third"는 인증서 비고란에 GPA 환산 정보를 별도로 기재해야 합니다. 일부 공직은 GPA 숫자로 판정하므로 미리 환산해 두는 게 좋습니다.
2. **복수전공·부전공**: Double Major는 한 번에 인증 가능. Minor는 성적표 비고에만 남고 별도 인증서는 발급되지 않음.
3. **졸업 연기(延期毕业)**: 과목 Fail로 인한 재수강·연기 시, 인증서상 "졸업일"은 실제 Degree Conferral Date를 기준으로 합니다. 공무원 지원 시 학년 판별에 그대로 반영되니 주의.
4. **미졸업(挂科未毕业)**: 인증 자체가 불가능. 반드시 홍콩으로 돌아가 재수강 후 졸업한 뒤에 신청해야 함.
5. **팬데믹 원격수업 기간(2020~2022)**: CSCSE가 해당 기간의 실제 홍콩 체류 일수에 대해 과도기 인정 정책을 운영했으나, **2023년부터는 일반 기준이 복원**되었으므로 신입생에게는 적용되지 않습니다.

## 자주 묻는 질문 (FAQ)

**Q1. 종이 졸업증장을 받아야만 류푸 인증을 신청할 수 있나요?**
아닙니다. Degree Certificate 전자본 + 전체 성적표만 있으면 온라인 접수가 가능합니다. 8대 모두 전자본 다운로드를 지원합니다.

**Q2. 8대가 아닌 홍콩 대학(예: 마카오대학會大學 OUHK, 행생대학 HSUHK)도 인증이 가능한가요?**
가능합니다. 단, 먼저 교육부 涉外監管信息網(`www.jsj.edu.cn`)에서 해당 대학이 추천 명단에 등재되어 있는지 확인해야 합니다. 명단에 없는 사립대학은 인증되지 않습니다.

**Q3. 과목 Fail로 1년 연기 졸업하면 인증서에 연기가 표시되나요?**
인증서에는 최종 Degree Conferral Date만 표시되며, 재수강·연기 내역은 표시되지 않습니다. 다만 성적표에는 남아 있어 공무원·落户 심사 시 추가 확인을 받을 수 있습니다.

**Q4. 학부 기간 중 한 학기 해외 교환을 다녀도 인증에 문제가 되나요?**
문제가 되지 않습니다. 교환 학기 성적은 주修 대학의 성적표에 통합 기재되며, 학위도 주修 대학에서 수여하므로 인증 주체 역시 주修 대학입니다.

**Q5. Honours Classification가 공무원시험에 영향을 주나요?**
일부 직무는 "GPA 3.0 이상" 같은 숫자 기준을 요구합니다. 8대 교무처에서 발급하는 Honours-to-GPA 대응표를 미리 받아 인증 신청 시 첨부하는 것이 안전합니다.

**Q6. 류푸 인증서는 유효기간이 있나요?**
없습니다. 인증서는终身 유효하며, 번호는 관련 부처에서 영구 조회 가능합니다.

**Q7. 류푸 인증 없이 민간기업에 입사해도 되나요?**
민간·외국·홍콩자본 기업은 대부분 원본 증서만으로 채용이 가능합니다. 다만 향후 체제 내(공무원·사업단위·落户)로 갈 경우 인증이 필요해지는데, 그때가 되면 자료가 분실되거나 학교 기록이 바뀔 수 있어 처음부터 받아두는 편이 안전합니다.

**Q8. 홍콩 학부 + 본토 석사를 모두 따면 인증은 어떻게 하나요?**
학부 졸업 직후 학부 인증을 먼저 진행합니다. 본토 석사는 국내 학력이므로 학信网으로 처리되며 류푸 인증이 필요 없습니다. 이후 해외 석사를 추가로 취득하면 그때 한 번 더 인증을 받으면 됩니다.
