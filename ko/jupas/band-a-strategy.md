# JUPAS Band A志愿填写终极指南：内地DSE考生怎样排最划算？

> 要点概括 — 2026 JUPAS数据显示，约90%的录取结果集中在Band A（首三志愿）；香港中文大学、香港科技大学两校更有99%的新生来自Band A。本文将系统拆解Band A排序逻辑、面试邀请触发机制、八大院校的加权计分差异，并给出一套实用的"冲/稳/保"三层填表策略，帮你把20格志愿填到最高性价比。

## 什么是JUPAS？内地考生必须知道的背景

对于通过香港中学文凭考试（DSE）升读香港大学的内地学生来说，JUPAS是绕不开的报考系统。

**JUPAS**（Joint University Programmes Admissions System，大学联合招生办法）是香港八所政府资助大学的统一本科联招平台，功能上类似内地的高考志愿填报系统，但底层机制差别很大：

| 对比维度 | 内地高考志愿 | 香港JUPAS |
|---|---|---|
| 志愿总数 | 视省份而定，一般6–45个 | 最多**20个** |
| 志愿分组 | 平行志愿 / 顺序志愿（按省份） | **5个组别**（Band A–E） |
| 投档逻辑 | 分数线 + 志愿顺序 | 按Band分组优先，Band内再按分数 |
| 录取时间 | 一次性统一投档 | 分Main Round + Clearing Round两轮 |
| 放榜后改选 | 一般不允许 | **放榜后3天可免费改选**（核心优势） |

**最关键的差异**：内地志愿一旦提交基本不可更改，而JUPAS在放榜后还给一次免费调整窗口。这是内地DSE考生独有的战略机会，也是本文策略设计的核心出发点。

## 一、Band A为什么这么关键？用数据说话

JUPAS允许最多填写**20个课程志愿**，分为5个组别：

| 组别 | 志愿序号 | 性质 |
|---|---|---|
| **Band A** | 第1–3志愿 | 最想去的 / 冲刺首选 |
| **Band B** | 第4–6志愿 | 稳健目标 |
| **Band C** | 第7–10志愿 | 保底选择 |
| **Band D** | 第11–15志愿 | 后备 |
| **Band E** | 第16–20志愿 | 极后备 |

### 派位统计：89.7%落在Band A

根据2023年JUPAS正式遴选公开数据（最新完整统计）：

- 申请总人数**39,948人**，**16,149人**（40.43%）在八大+都大获得学士学位正式录取
- 其中**14,485人（89.7%）**被Band A（首三志愿）录取
- Band B：927人（5.74%）
- Band C：339人（2.10%）
- Band D及以后合计：不足2.5%

### 各院校Band A录取占比

| 院校 | Band A占比 |
|---|---|
| 香港中文大学（CUHK） | 超过99% |
| 香港科技大学（HKUST） | 99% |
| 香港城市大学（CityU） | 接近90% |
| 香港浸会大学（HKBU） | 超过88% |

**结论**：Band A以后的志愿主要是"兜底"，真正的录取战场在首三格。一旦Band A填错，即使分数达标、面试发挥出色，也可能与心仪专业擦肩而过。

## 二、Band A的隐藏功能：面试邀请的触发器

很多考生以为Band A只是"表达偏好"，其实对不少课程来说，它是**面试资格的硬门槛**。

### 三类对Band A高度敏感的课程

**1. 必须面试 + 只邀请Band A申请人**

部分医科、法律、建筑、教育、心理学、社工等学位，院校会明确写明：**只向将该课程列入Band A的申请人发出面试邀请**。如果你把它放进Band B以后，就算DSE分数够，大概率连面试机会都没有。

- 典型例子：HKU内外全科医学士（MBBS）、CUHK MBChB、CUHK环球医学领袖课程（GPS）、HKU教育学士及言语及听觉科学双学位
- 多数JUPAS社工（SW）及临床心理学相关课程

**2. 同分时Band A优先**

录取分数接近时，院校会以"组别"作tie-breaker——同样27分的两个考生，放A1的永远先于放B1的。

**3. Band A申请人数部分公开**

部分院校会公开其课程的Band A申请人数。透明度越高，竞争越可量化，考生能据此估算激烈程度。

> **重点**：Band A是"课程录取你"的入场券，远远不只是"个人偏好的表达"。

## 三、JUPAS 2026关键时间表

| 日期 | 事项 |
|---|---|
| 2025年10月9日 | 报名开始（网上申请开放） |
| 2025年12月3日 17:00 | **报名截止** — 逾期报名需缴附加费 |
| 2025年12月5日 09:00 | 付费改选期开始 |
| 2026年7月15日 | **DSE放榜** |
| 2026年7月16–18日 | **免费改选期**（放榜后唯一一次免费调整） |
| 2026年8月5日 09:00 | **Main Round Offer** 公布 |
| 2026年8月6日 17:00 | 缴交HK$5,000留位费截止 |
| 2026年8月25日 09:00 | **Clearing Round Offer** 公布 |
| 2026年8月27日 14:00 | 最后查阅录取记录期限 |

### 两个关键策略时点

**时点1：2025年12月报名截止前（策略性初填）**

此时只有预测分数和模拟考成绩。原则是：**冲高不冲稳**，把最想去的课程全部放进Band A，因为放榜后还有一次免费改选机会。

**时点2：2026年7月16–18日（放榜后改选）**

真实DSE分数已出，你应该做的是：

1. 重新校准Band A、B、C的难度梯度
2. 确保Band A里仍有合理录取机会（不要三个都是不切实际的志愿）
3. Band C放稳入的保底学位

## 四、香港八大院校计分方法速查（2026年适用）

这是内地考生最需要吃透的部分。不同大学计分方式不同，**同一个DSE分数在不同院校可能差2–3分**，直接影响录取结果。这与内地高考"统一分数线"的逻辑完全不同。

### HKU（香港大学）

- **基本公式**：Best 6（最佳6科总分）
- **DSE分数转换**：5** = 8.5分、5* = 7分、5 = 5.5分、4 = 4分、3 = 3分
- **加权常见科目**：部分理学院、医科课程对Biology / Chemistry / Math加权×1.5或×2
- **语文要求**：English Language达3级、Chinese Language达3级（部分课程要求更高）

**示例**：某考生DSE成绩English 5*（7分）、Chinese 5（5.5分）、Math 5**（8.5分）、Biology 5*（加权×2 = 14分）、Chemistry 5（5.5分）、Economics 5（5.5分）。
HKU Best 6加权总分 = 7 + 5.5 + 8.5 + 14 + 5.5 + 5.5 = **46分**。

### CUHK（香港中文大学）

- **基本公式**：多数课程采用Best 5
- **DSE分数转换**：标准1–7分（5** = 7、5* = 6、5 = 5.5、4 = 4）
- **加权**：工程、计量金融、精算等课程会对Math / M1 / M2加权

### HKUST（香港科技大学）

- **基本公式**：Best 5 + 第6科Bonus（最多+5%）
- 采用独特机制：English + Math + 最佳Science + 最佳两个Category A选修，另可获第6科Category A / C加分
- **加权**：工程 / 商学院部分课程对Math加权

### PolyU（香港理工大学）

- 多数课程Best 5，部分工程、酒店管理用Best 6
- English和Math加权常见（×1.5或×2）

### CityU（香港城市大学）

- 多数Best 5，商学院的课程常用Best 6
- 对English / Math加权常见，尤其是商学、Data Science

### HKBU（香港浸会大学）

- 以Best 5为主
- 传理学院竞争激烈，实际录取分数往往高于表面要求

### LingU（香港岭南大学）

- Best 5
- 加权较少，对DSE 4个核心科 + 1个选修计分

### EdUHK（香港教育大学）

- Best 5或特定公式（因课程而异）
- 对English和Chinese加权常见（教师培训需要）

> **实用工具**：使用各大学官方JUPAS Score Calculator（如 admissions.hku.hk/apply/jupas/score-calculator）输入DSE分数，即可得出真实JUPAS分数。这是填表前必须完成的功课。

## 五、Band A排位的四条黄金法则

### 法则1："冲 / 稳 / 保"三档配置

这与内地"冲稳保"逻辑一致，但在JUPAS里可以更精确地量化：

| 位置 | 策略 | 合理分数差距 |
|---|---|---|
| **A1** | 冲刺（最心仪，难度高但有机会） | 你的预测分数 − 历年median ≥ −2分 |
| **A2** | 稳健（最心仪且有把握入） | 你的预测分数 ≈ 历年median |
| **A3** | 信心稳入（偏好 + 几乎必录） | 你的预测分数 > 历年median + 2分 |

**错误示范**：A1、A2、A3全是40分级别的医科、GPS、环球商业——一旦实际考出38分，连面试都没了。

**正确示范**：A1放医科（冲），A2放生物医学工程（稳），A3放护理或生物信息学（几乎稳入）。

### 法则2：所有面试课程都必须放BandA

如果你的心仪课程里有3个需要面试、3个不需要，**3个面试课程应该全部放进Band A**。

原因：
- Band A才有机会获得面试邀请
- 面试表现好可以弥补DSE分数差距
- 就算A1面试不理想，放榜后还能换回较稳的课程

### 法则3：每科加权要逐个算清楚

- 英文、数学成绩突出？→ 优先选对它们加权的课程（如CityU商学、HKUST工程）
- M1 / M2高分？→ 优先选Economics / QFin / Actuarial / Computer Science
- 中文强但英文一般？→ 避开对英文×2加权的商学和新闻学

### 法则4：20格志愿最好填满

Band D / E一定要有副学士（HD / AD）课程兜底。JUPAS 2023年仍有5.74%考生靠Band B录取，2.10%靠Band C——保住底线的关键就是最后几格。

## 六、三层选科思考框架

### 第一层：个人层面

- **兴趣 × 能力的交集**：光喜欢读不下来、或读得好但不喜欢，都会导致中途放弃
- **未来职业路径**：想当医生？律师？研究员？先从职业倒推课程
- **课程范畴 > 单一课程**：医疗、金融、教育、工程是范畴，每个范畴下有3–5个课程可组合
- 与升学老师、家长沟通，但最终决定权在你自己

### 第二层：课程层面

逐个课程对比：

- 课程内容（学什么）
- 学额（招生人数）
- 教学模式（讲座 vs 实习）
- 毕业资格（有无专业牌照？例如JUPAS Nursing = 香港注册护士资格）
- 收生要求（科目组合 + 加权）
- 历年median / LQ / UQ分数（JUPAS官网提供admissions scores PDF）
- 海外交流机会
- 开办院校特色

### 第三层：院校层面

- 院校文化（自由开放 vs 结构严谨）
- 校园氛围（宿舍文化、学生活动）
- 毕业要求（如CUHK书院制、HKUST四年核心课程）
- 特色计划（如CUHK Service Learning必修、HKU Common Core）
- 地理位置与生活成本

## 七、实战案例：三类考生的Band A配置

### 案例1：小坤（预测35分，立志商科）

小坤来自广东，DSE成绩English 5、Math 5*、Economics 5*，预测总分35分，目标是香港主流商学院。

**Band A配置：**
- **A1**：CUHK BBA Global Business（冲，CUHK median约37）
- **A2**：HKUST Business Management（稳，median约35）
- **A3**：PolyU Accounting and Finance（保，median约32）

**Band B（4–6）**：CityU Business、HKBU BBA Finance、LingU BBA

**Band C（7–10）**：UOW College HD in Business、HKU SPACE CC商科

**Band D–E**：副学士 / SSSDP兜底

> **加权提示**：如果小坤英文特别强（English 5*），而CityU Business对English×2加权，可以把CityU Business提到A1取代CUHK。这就是"加权计算"的实战价值。

---

### 案例2：小敏（预测40分，志在医科）

小敏是内地生，DSE成绩优异，目标香港医学院。

**Band A配置：**
- **A1**：HKU MBBS（冲）— 需面试，**必须放Band A**
- **A2**：CUHK MBChB（冲）— 需面试，**必须放Band A**
- **A3**：CUHK GPS环球医学领袖（顶级冲刺）或HKU BDS牙医

**Band B（4–6）**：HKU Pharmacy、CUHK Pharmacy、HKU Biomedical Engineering

**Band C**：HKU BSc Nursing、CUHK BNurs、HKUST BSc Biomedical Engineering

**Band D–E**：自资副学士医疗相关、都大护理

> **关键点**：HKU MBBS和CUHK MBChB都要求面试，且只邀请将其列入Band A的考生。如果小敏把任一个放进Band B，就直接失去面试资格，分数再高也录不了。

### 案例3：阿杰（预测28分，稳健型）

阿杰只想稳妥入读香港，不强求顶尖院校，更看重就业导向课程。

**Band A配置：**
- **A1**：CityU Computer Science（冲，median约28–30）
- **A2**：HKBU Data Analytics（稳）
- **A3**：LingU Data Science（稳入）

**Band B**：EdUHK幼教、PolyU SSSDP工程

**Band C**：HKU SPACE副学士、HKCC副学士（IT / Business）

**Band D–E**：职训局IVE HD

## 八、常见陷阱：5个不要踩的坑

1. **三个A位全是顶尖课程** — 一旦DSE失手，连面试机会都没有
2. **忽略加权** — 同样30分，加权后可能变32或28；算不清楚会错失机会
3. **放榜后不利用改选期** — 7月16–18日是唯一免费改选窗口，务必用足
4. **Band A放完全没兴趣的课程凑数** — 浪费关键格位，直接丢掉真正想要的机会
5. **迷信median** — Median只是中位数，LQ（下四分位）才是"勉强入读"的底线，A1应该对比LQ而不是median

## 九、放榜后改选期策略（2026年7月16–18日）

DSE放榜后的3天免费改选期，是整个JUPAS策略中最重要的窗口。建议按以下步骤操作：

### Step 1（7月15日当晚）
- 用各院校官方Score Calculator算出你的真实JUPAS分数
- 列出"安全入读清单"：所有你分数已超过median的课程

### Step 2（7月16日）
重新定义A1–A3：
- A1 = 你分数略低于median、但高于LQ的课程（冲）
- A2 = 你分数接近或超过median的课程（稳）
- A3 = 你分数高于UQ（上四分位）的课程（必录）

### Step 3（7月17日）
- 重排Band B（4–6）：选稳健但未被放入Band A的课程
- Band C兜底：副学士、SSSDP或冷门但稳入的学位

### Step 4（7月18日前）
- 最后确认：每个志愿都要反映真实偏好
- 此时改动，不会收任何费用

> **与内地高考的最大区别**：内地考生出分后基本无法改志愿（部分省份有极短窗口），而JUPAS给了整整3天。充分用好这3天，是内地DSE学生的独有优势。

## 十、Band A决策自我检查清单

对照以下问题检查你的Band A配置：

- [ ] A1、A2、A3有清晰的"冲 / 稳 / 保"梯度吗？
- [ ] 所有需要面试的课程是否都放在Band A？
- [ ] 我的强项科目（英 / 数 / 选修）是否用在加权课程上？
- [ ] 每个Band A课程都是我真正想读的？（不是"分数够就填"）
- [ ] 我查过这个课程过去3年的LQ分数吗？
- [ ] 放榜后的免费改选期我会重新检查并更新吗？
- [ ] Band B、C是否安排了真正"可接受"的兜底选项？

如果7条全部勾选，你的Band A策略已经达到顶尖水平。

## 常见问题（FAQ）

**Q：Band A三个位置一定要都填最顶尖的课程吗？**

A：不一定。Band A三个位置应该是"冲 / 稳 / 保"梯度配置。如果三个都是顶尖竞争课程（如HKU法律、CUHK GPS、HKUST QFin），一旦失手就连面试机会都没了。A3建议放"分数远超median"的课程作保险。

**Q：我把某个课程放得太高，院校会不会"嫌弃"我？**

A：不会。院校视Band A为"考生的明确偏好表达"，多数课程优先处理Band A申请者。只有当你的分数远低于LQ时，才可能连面试都没有；但放在Band A以外，机会更渺茫。

**Q：如果Band A三个位全部落空，Band B还有机会吗？**

A：有，但大幅下降。2023年Band B派位仅占5.74%。所以Band B（4–6）要放真正可能录你的课程，而不是把Band A填不下、又不甘心放弃的心愿堆到那里。

**Q：我分数不高（24–28分），还有必要分Band A / B / C策略吗？**

A：绝对有必要。在这个分数段，八大的部分课程（LingU、EdUHK、HKBU部分专业）仍在收生范围，同时自资学位、SSSDP和副学士的选择很多。Band A放稳健八大 + Band B放SSSDP + Band C放副学士，三层保障。

**Q：放榜后改选到底免不免费？什么时候？**

A：2026年7月16–18日是**免费改选期**。之后再改需要缴费（每次HK$150–300不等，视改动幅度而定）。务必在放榜后3天内重新校准Band A配置。

**Q：副学士 / HD可以放进Band A吗？**

A：技术上可以，但不建议。副学士门槛通常低于学士学位，应该放在Band C或之后作兜底。把副学士放进Band A会浪费学士学位的录取机会。

**Q：JUPAS院校会不会知道我的Band A以外的选择？**

A：院校只会知道该课程在你JUPAS列表中的Band分组（A/B/C/D/E），**不知道具体位置或其他院校的选择**。因此A1和A2在同一所院校没有"内部优先感"差异，院校只按Band分组进行遴选。

**Q：我应不应该在同一所院校放多个课程在Band A？**

A：看策略。如果你对某院校特别偏好（如HKU），可以A1 + A2都放HKU的不同课程。但A3建议换一所院校分散风险，避免"一棵树上吊死"。
